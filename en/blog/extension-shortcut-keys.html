How to set and change keyboard shortcuts for Chrome extensions

Sep 24, 2026 · Liquid Block Inc. · 4 min read

PostShareShare

You set and change Chrome extension shortcuts on the page you open by typing chrome://extensions/shortcuts in the address bar. Click the field for an extension and press the key combination you want (it must include Ctrl or Alt). LB TAB Layers is set to Alt+T (Option+T on Mac) out of the box.

Many Chrome extensions can be opened with a keyboard shortcut instead of the toolbar icon. For a tool you open dozens of times a day, not having to reach for the top-right corner of the screen makes a real difference.

Set or change an extension shortcut

  1. Open the shortcuts page. Type chrome://extensions/shortcuts in the address bar. You can also get there from chrome://extensions via “Keyboard shortcuts” in the left menu.
  2. Click the field (pencil icon) next to the action you want to assign.
  3. Press the keys. The combination must include Ctrl or Alt (Command, Control or Option on Mac).
  4. Choose the scope if offered: “In Chrome” or “Global”. “In Chrome” is right for almost everything.

“In Chrome” vs. “Global”

ScopeBehaviourRecommendation
In ChromeWorks only while you are using a Chrome windowUse this for most extensions
GlobalWorks even while you use other appsClashes easily with other apps’ shortcuts — use with care

When a shortcut can’t be set or doesn’t work

  • Another extension already uses it — a combination can belong to only one extension. The one installed later may end up with an empty field.
  • Chrome itself uses it — avoid combinations such as Ctrl+T that Chrome already has.
  • No modifier key — combinations without Ctrl or Alt can’t be registered.
  • The page grabs it first — some web apps have their own shortcuts that react before the extension does.

LB TAB Layers: Alt+T

From the moment you install it, LB TAB Layers opens with Alt+T (Option+T on Mac). To change that, find LB TAB Layers on chrome://extensions/shortcuts and set a new combination.

Frequently asked questions

Q. Where do I change keyboard shortcuts for Chrome extensions?

Type chrome://extensions/shortcuts in the address bar. You can also open it from chrome://extensions via “Keyboard shortcuts” in the left menu.

Q. Why doesn’t my extension shortcut work?

Usually because another extension or Chrome itself uses the same combination, the combination has no Ctrl or Alt, or the web app you are on uses the key first. Check the assignment at chrome://extensions/shortcuts.

Q. What is the shortcut for LB TAB Layers?

Alt+T (Option+T on Mac) by default. You can change it at chrome://extensions/shortcuts.
