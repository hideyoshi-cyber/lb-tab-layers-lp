Three ways to save tabs: add button, drag and drop, right-click

Sep 24, 2026 · Liquid Block Inc. · 4 min read

PostShareShare

There are three ways to save a tab in LB TAB Layers: 1) click Add current tab on a group to save the page you are on, 2) drag an open tab from the list into a group, or 3) right-click a tab and choose Save to Folder. The moment you save, the tab is also saved as a Chrome bookmark.

1. The Add current tab button

The quickest way to keep the page you are reading. Click Add current tab on the group you want, and the tab goes straight into it.

2. Drag and drop

Solo Tabs at the bottom of the side panel lists the open tabs that are not in any group. Drag one of them onto a group. It is the handy way to sort many tabs in one sitting.

3. Right-click → Save to Folder

Right-click a tab in Solo Tabs, choose Save to Folder, then pick the destination. Useful when you have so many groups that dragging gets awkward.

What happens when you save

  • If the same URL is already in that group, you’ll see Already added and it won’t be saved twice. Small differences such as a trailing slash are treated as the same URL.
  • If the same URL is in a different group, you’ll be asked to confirm first.
  • A thumbnail of the page is captured as you save (when thumbnails are turned on in the settings).

Working with saved tabs

To…Do this
Open itClick the saved tab
Change its display nameRight-click → Rename (the original page title is kept)
Move it to another groupDrag it, or right-click → Move to Group
Add a noteRight-click → the item with the notepad icon
Remove it from the groupRight-click → Delete

Saved tabs stay saved when you close them. The side panel shows at a glance which saved tabs are currently open and which are closed.

Frequently asked questions

Q. What happens if I save the same page twice?

If the same URL is already in that group you will see “Already added” and it is not saved again. If it is in another group, you will be asked to confirm.

Q. Can I rename a saved tab?

Yes. Right-click the saved tab and choose Rename to change how it appears in the side panel. The original page title is kept.
