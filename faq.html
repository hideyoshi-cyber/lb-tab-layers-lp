はじめる前に

拡張機能とは何ですか？

ブラウザに、あとから足せる小さなアプリです。「Chrome に追加」を押すだけで入り、再起動はいりません。Google の公式のストア（Chrome ウェブストア）から配られていて、いつでも消したり、止めたりできます。

無料で使えますか？

はい。タブの保存、検索、まとめて開く・閉じる、ブックマークとの同期は、無料で使えます。インストールから3か月は、PRO の機能もすべて試せます。

どのブラウザで使えますか？

Google Chrome（114 以降）で使えます。Windows・Mac・Linux・ChromeOS に対応しています。Edge 版は準備中です。

今のブックマークは、どうなりますか？

そのまま使えます。Chrome のブックマークを取り込んで、案件ごとのグループとして整理できます。もとのブックマークが消えることはありません。

タブを100個開くと、パソコンが重くなりますか？

Chrome のタブは、1つごとにメモリを使います。LB TAB Layers では、使わないタブをブックマークとして保存してから閉じられるので、メモリが空きます。必要になったら、まとめて開き直せます。

データと安心

「ブックマークに保存される」とは、どういう意味ですか？

保存したタブは、Chrome のブックマークと同じ場所に入ります。独自の保存場所ではないので、拡張機能を消しても、パソコンが止まっても、ブックマークとして残ります。

パソコンを再起動したあと、タブを戻せますか？

戻せます。保存したタブは Chrome のブックマークに入っているので、再起動や強制終了のあとでも、サイドパネルからまとめて開けます。

拡張機能を消したら、データはどうなりますか？

保存したタブは、Chrome のブックマークとして残ります。入れ直すと、グループとタブが戻ります。テーマや色、タグなどの設定は、このパソコンの中に保存しているので、消すとなくなります。

データは、外部に送られますか？

タブとグループのデータは、ブラウザの中に保存します。当社のサーバーには送りません。届くのは、ライセンスの確認に使う匿名の番号だけです。アイコンの表示や検索の候補のために、一部の外部サービスと通信します。くわしくは プライバシーポリシーをご覧ください。

Windows と Mac の両方で使えますか？

使えます。Chrome のブックマークの同期を使うと、複数のパソコンで同じグループを使えます。

料金

PRO は月額ですか？

いいえ、買い切りです。PRO 版は $9.99 で、一度のお支払いでずっと使えます。

無料版と PRO 版の違いは何ですか？

無料版は、グループ5個・テーマ3種までで、基本の機能が使えます。PRO 版は、グループの数に上限がなく、すべてのテーマに加えて、ダッシュボード、修正指示、AI 検索などが使えます。くわしくは プランの比較をご覧ください。

機能について

修正指示は、どの動画で使えますか？

YouTube（ショートを含む）、Vimeo、Google ドライブ、Web ページに埋め込まれた動画で使えます。パソコンの中の動画ファイルも開けます。著作権保護（DRM）のかかった動画は、黒く写ります。修正指示は PRO の機能で、お試しの期間中は使えます。

OneTab との違いは何ですか？

いちばんの違いは、保存する場所です。LB TAB Layers は Chrome のブックマークに保存するので、拡張機能を消してもデータが残ります。サイドパネルに常に出しておける点、案件ごとにまとめて開閉できる点も違います。くわしくは OneTab との比較へ。
