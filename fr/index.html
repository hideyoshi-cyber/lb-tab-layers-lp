Questions fréquentes

Est-ce gratuit ?

Oui. Enregistrer, rechercher, ouvrir et fermer en groupe : tout cela est gratuit. Pendant les 3 premiers mois, vous pouvez essayer toutes les fonctionnalités. PRO est un achat unique, sans abonnement mensuel.

Que deviennent mes favoris actuels ?

Vous les gardez tels quels. Les favoris de Chrome sont importés comme ils sont, et vous pouvez les organiser.

Que deviennent mes données si je supprime l’extension ?

Les onglets enregistrés restent dans les favoris de Chrome. Les réglages, comme le thème ou les couleurs, sont effacés.

Avec quels navigateurs fonctionne-t-elle ?

Avec Google Chrome (114 ou version ultérieure). Compatible Windows, Mac, Linux et ChromeOS. La version Edge est en préparation.
