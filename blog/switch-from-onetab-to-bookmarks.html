OneTab から
Chrome のブックマークへ移す

2026.10.27 · Liquid Block Inc. · 読了 7分

ポストシェアLINE送るB!ブックマーク

OneTab に貯めたタブは、OneTab の書き出し（Export / Import URLs）で表示されるテキストをコピーし、LB TAB Layers の「OneTab から乗り換える」に貼り付けると、Chrome のブックマークとしてまとめて取り込めます。v2.9.0 で追加した機能で、取り込みは無料です。空行で区切られたまとまりごとにサブグループができます。取り込むのは URL とタイトルだけなので、OneTab でのグループ名・スター・メモなどは引き継がれません。

OneTab は、ボタンを1回押すだけで、開いているタブを一覧にまとめられる定番の拡張機能です。公式サイトでは、一覧の書き出し・読み込みのほか、フォルダやタスク、メモ、暗号化した同期などの機能も紹介されています。

一方で、「貯めたタブを Chrome のブックマークとして持っておきたい」「案件ごとに分けて、サイドパネルから開いたり閉じたりしたい」という理由で、移す先を探す人もいます。この記事では、OneTab に貯めたタブを、Chrome のブックマークへまとめて移す方法を説明します。

💡 移し終わるまで、OneTab は削除しないでください。OneTab の公式ヘルプでは、OneTab をアンインストールすると保存したタブがブラウザから削除される、と案内されています。まず書き出しのテキストを控えておき、移し終わったことを確かめてから整理しましょう。

1. Chrome の標準機能だけで移す方法

拡張機能を増やさずに移すなら、OneTab からタブを開き直して、Chrome の機能でブックマークにする方法があります。

1

OneTab で、移したいまとまりを開き直す

OneTab の一覧から、移したいまとまりのタブをすべて開き直します。ほかのタブと混ざらないよう、新しいウィンドウで作業すると分かりやすくなります。OneTab の設定によっては、開き直したタブが OneTab の一覧から消えるので、先に書き出しのテキストを控えておくと安心です。

2

「すべてのタブをブックマークに追加」

Ctrl+Shift+D（Mac は ⌘+Shift+D）を押すか、Chrome のメニューの「ブックマークとリスト」→「すべてのタブをブックマークに追加」を選びます。そのウィンドウのタブがすべて入るので、ほかのタブは閉じておきます。

3

フォルダの名前を付けて保存する

新しいフォルダの名前を付けて保存します。まとまりの数だけ、1〜3をくり返します。

まとまりが少なければ、これで十分です。ただ、まとまりの数だけ「開く→保存→閉じる」をくり返すことになり、数百件あると、一度にたくさんのタブを開くことになります。

なお、Chrome の「ブックマークと設定をインポート」は、ほかのブラウザのデータや、HTML 形式のブックマーク ファイルを読み込む機能です。OneTab の書き出しテキストは、そのままでは読み込めません。

2. LB TAB Layers の「OneTab から乗り換える」で移す方法

v2.9.0 で、OneTab の書き出しテキストを貼り付けて取り込む機能を追加しました。タブを1つずつ開き直す必要はありません。取り込みは無料です。

1

OneTab で、書き出しのテキストを表示する

OneTab の画面で「Export / Import URLs」（URL の書き出し・読み込み）を開くと、保存したタブが文字の一覧で表示されます。OneTab の版によって、メニューの場所や名前が違うことがあります。

2

テキストをすべてコピーする

テキストの欄をクリックして Ctrl+A（Mac は ⌘+A）で全部を選び、Ctrl+C（Mac は ⌘+C）でコピーします。念のため、メモ帳などに貼り付けて、控えとして保存しておくと安心です。

3

「OneTab から乗り換える」を開く

Alt+T（Mac は Option+T）で LB TAB Layers を開き、右上の歯車（「設定」）→「データと同期」→「はじめる・乗り換える」の「OneTab から乗り換える」を押します。

4

貼り付けて、件数を確かめる

テキストの欄に貼り付けると、「3グループ・120件を取り込みます」のように、読み取れた数が表示されます。OneTab 側の件数とくらべて、大きく違わないか確かめます。

5

取り込み先の名前を決めて「取り込む」

「取り込み先のグループ名」は、最初は「OneTab から」になっています。好きな名前に変えてもかまいません。「取り込む」を押すと、件数が多いときは「取り込み中… 50 / 120」のように進み具合が出て、終わると「120件を取り込みました」と表示されます。

3. 取り込むとどうなるか

OneTab の書き出しテキストは、1行に1つのタブ（「URL | タイトル」）が並び、まとまりの間に空行が入る形です。LB TAB Layers は、この空行を区切りとして読み取ります。

OneTab の書き出しLB TAB Layers
テキスト全体取り込み先のグループ（最初の名前は「OneTab から」）
空行で区切られたまとまりその中のサブグループ「グループ 1（40件）」「グループ 2（25件）」…
まとまりが1つだけのときサブグループは作らず、取り込み先のグループに直接入る
1行（URL | タイトル）保存したタブ1件（Chrome のブックマーク1件）

Chrome のブックマークでは、「LB TAB Layers」フォルダの中に「OneTab から」フォルダができ、その中に「グループ 1（40件）」などのフォルダが並びます。ふつうのブックマークなので、LB TAB Layers を削除しても残ります。Chrome の同期でブックマークをオンにしていれば、Google アカウントでほかのパソコンにも同期されます（Chrome の機能です）。

引き継がれるもの・引き継がれないもの

  • 引き継がれる：ページの URL とタイトル。タイトルがない行は、URL がそのまま名前になります。
  • 引き継がれない：OneTab でのまとまりの名前やフォルダ、スター、タスク、メモ、保存した日付など。
  • 読み飛ばす行：http:// や https:// で始まらない行は、数に入れずに読み飛ばします。ブックマークにできない URL も、その行だけ飛ばします。
  • 重複：すでにほかのグループに保存してある URL も取り込みます。その件数は、完了のお知らせに「（うち○件は、すでに別のグループに保存済みです）」と出ます。

4. 取り込んだあとに整える

  • サブグループの名前を変える：グループを右クリックするか「…」（その他のアクション）から「編集（名前・アイコン・色）」を選びます。「グループ 1（40件）」を「A社の資料」のような案件名にすると、あとで探しやすくなります。
  • タブを別のグループへ動かす：タブをドラッグして、入れたいグループへ移します。
  • いらないタブを消す：タブを右クリックして「削除」を選びます。移すのをきっかけに、もう見ないページを手放すのもおすすめです。
  • 使うときは ▶、閉じるときは ■：グループの ▶ で中のタブをまとめて開き、■ で閉じます。閉じても保存はそのままです。

グループとサブグループの使い方は「【機能ガイド】グループとサブグループ」で説明しています。

5. 無料版で使うときに知っておきたいこと

取り込みは無料で、グループの数の上限で止まることはありません。ただし、取り込んだグループとサブグループも、ふつうのグループと同じく無料版の5グループ（サブグループ込み）に数えられます。

  • インストールから3か月のトライアル中（と PRO 版）は、すべてのグループを使えます。
  • トライアルが終わった無料版では、一覧の上から5グループだけを操作でき、それより下は「このグループはロックされています」と表示されます。取り込んだグループは一覧の最後に入るので、もともとグループが多い人はロックされる側に入りやすくなります。
  • ロックされても、タブは Chrome のブックマークとして残っています。

グループを増やしすぎないためのコツです。

  • 1つのグループにまとめて取り込む：貼り付ける前に、メモ帳などでテキストの空行を消しておくと、まとまりが1つとして読まれ、取り込み先のグループ1つに全部入ります。
  • 今使う分だけ取り込む：テキストの一部だけを貼り付けても取り込めます。残りは控えのテキストとして手元に置いておけます。
  • 使い終わったグループはアーカイブ：「…」の「アーカイブ」で片付けたグループは、5グループに数えません（→「【機能ガイド】アーカイブ」）。

6. OneTab と併用するのもあり

「とにかく今のタブを全部しまいたい」ときは、OneTab の1クリックが手軽です。案件ごとに分けて開いたり閉じたりするのは LB TAB Layers、と役割を分けて、しばらく両方を使うこともできます。

保存のしかたの違いは「セッション保存とブックマーク保存、どちらが安全か」で、拡張機能を削除したときにデータがどうなるかは「拡張機能を削除したらデータはどうなる？」でまとめています。Session Buddy を使っている人は「Session Buddy から乗り換えるときの手順」もどうぞ。

よくある質問

Q. OneTab のデータを、そのまま読み込めますか？

OneTab の拡張機能の中のデータを直接読むことはできません。OneTab の「Export / Import URLs」で表示されるテキストをコピーして、LB TAB Layers の「設定」→「データと同期」→「はじめる・乗り換える」の「OneTab から乗り換える」に貼り付けてください。

Q. OneTab のグループ名は引き継がれますか？

引き継がれません。書き出しのテキストから読み取るのは URL とタイトルだけで、サブグループは「グループ 1（40件）」のような名前になります。あとから「編集（名前・アイコン・色）」で変えられます。

Q. 無料版でも取り込めますか？

取り込めます。取り込みは無料で、件数の上限もありません。ただし取り込んだグループも無料版の5グループ（サブグループ込み）に数えられ、トライアル終了後は一覧の上から5グループ以外がロックされます。タブは Chrome のブックマークとして残ります。

Q. 取り込んだあと、OneTab は削除してもいいですか？

移したいタブがすべて LB TAB Layers に入ったことを確かめ、OneTab の書き出しテキストを控えとして保存してからにしてください。OneTab の公式ヘルプでは、アンインストールすると保存したタブが削除されると案内されています。
