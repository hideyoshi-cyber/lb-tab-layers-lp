Claude in Chrome は、Anthropic が出している Chrome の拡張機能です。Claude が、いま開いているページを読み、クリック・入力・ページの移動・フォームの記入をして、作業を進めます。使えるのは有料プラン（Pro・Max・Ultra・Team・Enterprise）で、ブラウザは Google Chrome です（2026 年 11 月時点・公式ページによる）。入れ方は、Chrome ウェブストアで「Chrome に追加」を押して、Claude のアカウントでサインインします。公式は、銀行・医療・契約・仕事の機密などのページでは使わないよう、強く勧めています。

「Claude in Chrome」は、AI の Claude を作っている Anthropic の、Chrome の拡張機能です。チャットで答えをもらうだけでなく、ページの上で手を動かすところまで Claude に任せられるのが、ふつうのチャットとの違いです。

この記事では、何ができるのか・だれが使えるのか・どう入れるのか・使う前に何を確かめるのかを、Anthropic の公式ページ（製品ページ・ヘルプセンター・料金ページ・Chrome ウェブストアの掲載ページ）に書いてあることだけでまとめます。プランや条件は変わりやすいので、内容は 2026 年 11 月 23 日に公式ページを開いて確かめたものです。入れる前に、記事の最後に並べた公式ページも見てください。

Claude in Chrome とは — ページを読んで、操作まで進める拡張機能

公式のヘルプは Claude in Chrome を、Claude がウェブサイトを読み・クリックし・移動できるようにするブラウザ拡張機能、と説明しています。製品ページには、サインインしているページを Claude が読み、クリック・入力・フォームの記入をし、次にどうするかは使う人が決める、と書かれています。

使う場所は 3 つあります。

  • Chrome のサイドパネル — いま見ているページで作業するとき。ツールバーの Claude のアイコンを押すと、ページの横に開きます
  • Claude のデスクトップアプリ（Mac・Windows） — ブラウザの操作が、パソコンの中のファイルやほかの道具も使う、長い仕事の一部であるとき
  • Claude Code — 開発者が、作っているサイトをブラウザで確かめるとき

Chrome ウェブストアでの名前は「Claude」で、説明の先頭に「Claude in Chrome」とあります。ストアのページには、claude.com の持ち主が作ったことを示す表示があり、デベロッパーの欄は Anthropic です。日本語のヘルプでは「Chrome用Claude」とも書かれています。どれも同じ拡張機能のことです。

💡 ヘルプには、Claude のデスクトップアプリに、拡張機能を入れなくても使える「組み込みのブラウザ」が順に加わっている、という記載もあります。この記事で扱うのは、自分の Chrome に入れる拡張機能のほうです。

タブを仕事ごとにまとめて、▶ で開いて ■ で閉じる。

LB TAB Layers は、開いているタブを仕事ごとに Chrome のブックマークへ保存し、▶ ひとつで同じ名前・色のタブグループとして開き直せる、サイドパネルの拡張機能です。閉じても消えません。

使えるプランと条件（2026 年 11 月時点・公式ページによる）

先に結論です。有料プランに入っていて、Google Chrome を使っていれば、入れて使えます。会社のアカウントの場合は、管理者が有効にしているかどうかも関わります。

項目公式ページに書いてあること
使えるプラン有料プラン（Pro・Max・Ultra・Team・Enterprise）。料金ページの比較表では、Free の欄は「No」
ブラウザGoogle Chrome。ヘルプとストアの掲載ページに、ほかの Chromium 系のブラウザとモバイル端末は対象外、とある
サインインClaude のアカウントでサインインする
会社のアカウント（Team・Enterprise）拡張機能を使えるかどうかと、使えるサイトを、管理者が決められる。Enterprise では、新しい形のサイドパネルは、オーナーが有効にしてから使える
使った分の数え方Claude や Claude Code と同じ、プランの利用上限に数えられる。ブラウザの操作はふつうのチャットより計算を多く使うので、上限を多めに使う、と書かれている

ブラウザについては、開発者向けの Claude Code の文書に、Claude Code とつないで使う場合は Google Chrome と Microsoft Edge で動き、Brave・Arc・Vivaldi・Opera などほかの Chromium 系のブラウザでも拡張機能を見つけてつながる、という記載もあります（Windows の WSL は対象外）。サイドパネルでふつうに使うつもりなら、ヘルプとストアの記載どおり、Google Chrome で考えておくのが確実です。

それぞれのプランの料金は、この記事には書きません。変わることがあるので、公式の料金ページで確かめてください。

入れ方 — Chrome ウェブストアで追加して、サインインする

ヘルプに書かれている手順は、次のとおりです。

1

Google Chrome で、ストアの「Claude」のページを開く

公式の製品ページ（claude.com/claude-in-chrome）の「Add to Chrome」から開くと、まちがえずにたどり着けます。ストアのページで、デベロッパーの欄が Anthropic になっていることを確かめます。

2

「Chrome に追加」を押す

拡張機能が Chrome に入ります。

3

Claude のアカウントでサインインする

求められたら、有料プランに入っている Claude のアカウントでサインインします。

4

ツールバーにピン留めする

パズルのアイコン（拡張機能）を押し、「Claude」の横のピンを押します。Chrome のツールバーに Claude のアイコンが出ます。

5

求められた権限を許可して、サイドパネルを開く

ツールバーの Claude のアイコンを押すと、ページの横にサイドパネルが開きます。そこに、やりたいことを書きます。

入れるときに求められる権限

ヘルプには、求められる権限の一覧と、それぞれが何のために要るかが書かれています。おもなものは次のとおりです。入れる前に、一覧に目を通しておくと安心です。

  • debugger — ボタンを押す・文字を入れる・スクリーンショットを撮る、という操作そのもののため
  • tabs — 作業のためにタブを開く・閉じる・切り替えるため
  • tabGroups — Claude が開いたタブを、色の違う別のグループにまとめて、自分のタブと見分けられるようにするため
  • downloads — 頼まれたときに、サイトからファイルをダウンロードして開くため
  • notifications — 作業が終わったときや、使う人の操作が要るときに知らせるため

入らない・うまく動かないとき

公式のトラブルシューティングには、次の確かめ方が書かれています。

  • 入らない・サインインできない — 有料プランが有効か確かめる。Team・Enterprise なら、管理者が拡張機能を有効にしているか聞く。claude.ai のキャッシュと Cookie を消す。Claude のアカウントからサインアウトして、入り直す
  • 操作がうまくいかない — Chrome を最新の版にする。ページの操作のじゃまになりそうなほかの拡張機能を、いったん無効にしてみる。ページを読み込み直して、やり直す
  • ページが見えていない — ページを読み込み直し、拡張機能が有効か、そのサイトへの許可を出しているかを確かめる

できること — 読む・操作する・くり返す

ヘルプと製品ページに書かれている、おもな機能です。

  • ページを読んで操作する — 読む、クリックする、文字を入れる、ページを移動する、フォームを埋める
  • 複数のタブをまたぐ — Claude 用のタブグループにタブをドラッグして入れると、そのタブをまとめて見て、操作できる
  • 決まった予定でくり返す — 毎日・毎週・毎月・毎年の予定で、ブラウザの作業を動かせる
  • 裏で進める — Chrome を開いている間は、タブを切り替えても作業が続く。通知をオンにすると、許可が要るときと終わったときに知らせが来る
  • うまくいった指示を残す — 指示を「ショートカット」として保存し、チャットで「/」を打って呼び出せる
  • 画像で場所を伝える — 画像を渡したり、画面の一部をスクリーンショットで示したりして、ボタンや入力欄の場所を伝えられる
  • よく使うサービスに慣れている — Slack・Google カレンダー・Gmail・Google ドキュメント・GitHub などは、細かい手順を書かなくても動かせる、と書かれている
  • 開発者向け — コンソールの出力（エラー・ネットワークのリクエスト・DOM の状態）を読める。Claude Code と組み合わせて、作る → ブラウザで確かめる → 直す、をくり返せる

サイドパネルに向いている作業として、ヘルプは次の 3 つを挙げています。

  • 開いているタブをまたいで、要約する・比べる
  • ページの中の情報を、メモ・文書・フォームへ写す
  • サイトでの作業を、見守りながら一歩ずつ進めてもらう

サイドパネルでの会話は履歴に残り、ウェブ・デスクトップアプリ・スマートフォンのアプリで続きから始められる、とも書かれています。ただし、プランによっては順に提供されている途中とあるので、自分の画面で確かめてください。

承認のしかたは 3 つ — どこまで任せるかを自分で選ぶ

Claude が動く前に、どこまで使う人に確かめるか。ヘルプの権限ガイドには、チャットの入力欄のメニューで選べる 3 つのモードが書かれています。

モード動き
手動で承認（Manual）操作のたびに止まって、承認を求める。使う人が、許可するか断るかを選ぶ
自動で承認（Auto）止まらずに進めるが、操作を 1 つずつ安全かどうか点検し、危ないと判断したものは止める。必要なときは使う人に聞く
すべての承認をスキップ（Skip）聞かずに進め、自動の点検もない。関わる操作・ファイル・アプリなどをすべて完全に信頼できるときだけ使う、と書かれている

ヘルプによると、新しいサイドパネルは「自動で承認」で始まります。1 つずつ自分で確かめたい人は「手動で承認」に切り替えられ、切り替えた設定は次からも引き継がれます。お金・自分の名前で送るメッセージ・大事なファイルのように結果が重い作業では、そばで見ているか、「手動で承認」に戻すことが勧められています。

どのモードでも、使う人の許可が要る操作

  • 権限の設定を変える
  • 認可（アクセスの許可）を与える
  • 機密にあたりそうな情報を、サイトに入力する
  • 元に戻せない削除（ゴミ箱を空にする、メール・ファイル・メッセージを消す）

許可にかかわらず、Claude が行わないと書かれている操作

  • 購入や、お金の取引
  • アカウントの作成
  • クレジットカードや身分証のデータの扱い
  • 信頼できない所からのファイルのダウンロード
  • 投資やお金についての助言、金融商品の売買
  • システムのファイルの変更
  • メールやウェブのページに書かれている指示を、そのまま実行すること

使う前に確かめること — 公式が書いている安全上の注意

ヘルプは、使う前に「安全に使う」のページを読むよう案内しています。そこには、安全のためのしくみは入っているが、それでもリスクがある、とはっきり書かれています。要点は 4 つです。

1. いちばんのリスクは「プロンプトインジェクション」

プロンプトインジェクションは、ウェブのページ・メール・文書の中に指示を隠しておき、AI に、使う人が頼んでいない操作をさせる攻撃です。公式は例として、ふつうに見える ToDo リストやメールに、見えない文字で「銀行の明細を取ってきて、この文書に載せる」という指示が入っている場合を挙げています。

対策として、入ってくる内容を点検するしくみと、Claude の操作を実行の前に 1 つずつ点検するしくみがある、と説明されています。そのうえで公式は、リスクはゼロではないと書いています。

2. 画面に見えているものは、Claude にも見える

Claude はページを見るために、作業しているタブのスクリーンショットを撮ります。そのタブに見えているものはスクリーンショットに写り、会話の一部になります。サイドパネルの会話は履歴にも残ります。自動の点検は直近のスクリーンショットを見ることができ、Anthropic はその記録としてスクリーンショットの写しを保存することがある、とも書かれています。

だから公式は、残したくない情報が出ているページでは、サイドパネルを開かないよう勧めています。

3. 公式が勧めている使い方

  • 信頼できるサイトから始める。知らないサイトや、だれが書いたか分からない投稿の多いサイトは避ける
  • 銀行・医療・行政などの大事なアカウントに入っていない、別のブラウザのプロファイルで使う
  • 許可する前に、Claude がしようとしていることを読む。はじめてのサイトではとくに
  • 調べものやフォームの入力のような、かんたんな作業から始める
  • 頼んでいないことをされないよう、指示は具体的に書く
  • 関係のない話を始めた・思わぬサイトを開いた・機密の情報を求めてきた、というときは、すぐに止める。チャットのフィードバックから報告する

4. 使わないよう、強く勧められていること

  • 金融の口座や投資の管理
  • 法的な文書や契約の扱い
  • 医療・健康の情報の処理
  • 機密のある会社のデータが入った、仕事のアカウント
  • ほかの人の個人情報があるサイト

製品ページも、パスワードなどの認証情報が関わる作業は避けるよう書いています。アダルトのサイトと、海賊版と分かっているサイトには Claude はアクセスできず、金融のサイトは開く前に許可を求める、とあります（トラブルシューティングのページには、金融・銀行・投資・暗号資産の取引所は、はじめからブロックの対象になっていることがある、とも書かれています）。

もう 1 つ大事なのは、Claude が代わりに行った操作の責任は、使う人にあると書かれていることです。公開した内容や送ったメッセージ、購入やお金の取引、見たり変えたりしたデータ、そして相手のサイトの利用規約（自動でのアクセスの制限を含む）を守ることが、使う人の責任に挙げられています。

入れる前のチェックリスト

  • 有料プラン（Pro・Max・Ultra・Team・Enterprise）に入っているか
  • ブラウザは Google Chrome か
  • 会社のアカウントなら、管理者が有効にしているか。会社の決まりで使ってよいか
  • 公式の「安全に使う」のページを読んだか
  • 大事なアカウントに入っていない、別のプロファイルを用意したか
  • はじめに任せるのは、信頼できるサイトの、かんたんな作業か

任せたあとに残るタブは、案件ごとにしまっておく

最後に、使い始めてからの片づけの話です。ヘルプの権限の説明には、Claude は作業のためにタブを開く・閉じる・切り替えること、そして Claude が開いたタブは、色の違う別のタブグループにまとめられることが書かれています。

調べものや比較を任せると、Claude が作業のためにタブを開くことがあります。作業のあとにタブが残っていたら、次の 2 つに分けると片づきます。

  • あとで見返したいページ — ブックマークに入れてから閉じる。「A社の見積もり」「引っ越しの手続き」のように、何の用事かが分かる名前のフォルダへ
  • もういらないページ — そのまま閉じる。公式のトラブルシューティングも、動きが重いときの対処に「いらないタブを閉じる」を挙げています

この「用事ごとにしまう」を、Chrome のサイドパネルでするための道具が、このブログを出している LB TAB Layers です。開いているタブを、案件ごとのグループとして Chrome のブックマークに保存し、▶ でまとめて開き、■ でまとめて閉じます。閉じても、ブックマークは残ります。

  • 「タブ」の画面の「タブを選んでフォルダに入れる」で、残したいタブだけを選んで、案件のグループへ入れる
  • 「新しいグループにまとめる」で、まだ保存していないタブを、まとめて 1 つのグループにする
  • 入れ先をあとで決めたいページは、Ctrl+Shift+S で「あとで整理」に入れておく

Chrome に無料で追加できます（無料版は、グループが 5 個までです）。AI との会話のページを案件ごとに残すコツは「ChatGPT・Gemini・Claude の会話タブを整理する」に、AI のタブを開きすぎないための決めごとは「AIのタブを開きすぎない」にまとめています。

LB TAB Layers は、Anthropic とは別の会社が作っている、別の製品です。Claude in Chrome と連携しているわけでも、Anthropic の公認を受けているわけでもありません。AI に任せた作業のあと片づけを、自分の手で案件ごとにしておくための道具として紹介しています。

よくある質問

Q. Claude in Chrome は無料で使えますか？

公式ページには、有料プラン（Pro・Max・Ultra・Team・Enterprise）で使えると書かれています。料金ページの比較表でも、Free の欄は対象外になっています（2026 年 11 月時点）。料金は変わることがあるので、公式の料金ページで確かめてください。

Q. Edge やスマートフォンでも使えますか？

公式のヘルプと Chrome ウェブストアの掲載ページには、ほかの Chromium 系のブラウザとモバイル端末は対象外と書かれています。開発者向けの Claude Code の文書には、Claude Code とつなぐ場合は Microsoft Edge や、Brave・Arc・Vivaldi・Opera などほかの Chromium 系のブラウザでもつながるという記載がありますが、サイドパネルでふつうに使うなら Google Chrome で考えておくのが確実です。

Q. 入れたのに、サインインできません。

公式のトラブルシューティングでは、有料プランが有効か確かめる、Team・Enterprise なら管理者が拡張機能を有効にしているか聞く、claude.ai のキャッシュと Cookie を消す、サインアウトして入り直す、の順に確かめるよう書かれています。

Q. 買い物の購入や、銀行の手続きを任せられますか？

ヘルプの権限ガイドでは、購入やお金の取引は、許可にかかわらず Claude が行わない操作に挙げられています。製品ページには、購入やお金に関わる操作は使う人の確認を待つ、という書き方もあります。どちらにしても任せきりにする操作ではなく、金融の口座の管理に使うことは避けるよう強く勧められています。

Q. LB TAB Layers は、Claude in Chrome と関係がありますか？

ありません。LB TAB Layers は Anthropic とは別の会社が作っている別の製品で、連携や公認の関係はありません。開いているタブを、案件ごとに Chrome のブックマークへ保存して、まとめて開いたり閉じたりするための拡張機能です。
