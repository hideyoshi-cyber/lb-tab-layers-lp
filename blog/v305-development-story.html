【開発ストーリー】3.0.5
自分で使って、作り直した

2026.11.18 · 開発：LB開発チーム（株式会社リキッドブロック） · 読了 8分

ポストシェアLINE送るB!ブックマーク

3.0.4 と 3.0.5 は、新しい機能「修正指示」を自分たちの仕事で使い、出てきた不満から作り直した版です。設定しないと使えないショートカットをやめ、説明の並んだ画面をボタン1つにし、動画から離れずに「止める → 書く → Enter」で続けて書ける形にしました。修正指示は 3.0.4 で入り、3.0.5 で画面をさらに軽くしました。

3.0.4 で、動画や Web ページに番号つきの指示を書く「修正指示」が入りました。じつは、この機能は最初の形でいちど出来上がっていました。出す前に、私（代表の蔡本）が自分の仕事で1日使ってみて、このままでは出せないと判断しました。この記事は、3.0.4 と、続く 3.0.5 で何を直したかの記録です。

分けるのは「考え」、つなげるのは「手の動き」

これまでの修正指示は、こう書いていました。動画をいちど通して見て、気になった所の時間をメモする。その時間に合わせて止めて、スクリーンショットを撮る。PowerPoint に貼って、指示を書く。

困ったのは、書いているうちにカットの流れを忘れてしまうことです。目の前の1枚の絵のことしか考えられなくなります。見返すと、同じ指示がだぶっている。抜けている所がある。書かなくてよかったことまで書いている。直しながら、なくした時間にいつもイライラしていました。

「調べものは「集める」と「分ける」を同時にやるから疲れる」と、前に書きました。修正指示は、いくつもの作業を1つにまとめた機能です。逆のことを言っているようで、言っていることは同じです。分けたいのは頭の中の判断の種類、つなげたいのは手の動きです。

修正指示を書くとき、考えていることは「どこを、どう直すか」の1つだけです。それなのに手は、再生・停止・スクリーンショット・貼り付け・書く、と道具の間を行き来していました。その切れ目のたびに、考えも途切れます。だから、止めて、書いて、Enter で再生が続く形にしました。

もう1つ、修正のためだけに、よく知らないサービスのサーバーへ動画を上げるのは、気が進みません。お客さまの映像なら、なおさらです。そこで、手元の動画ファイルをそのまま開いて、同じように書けるようにしました。書いた指示と画像は、パソコンの中に保存されます。

「ショートカットを設定する、は無責任」

最初の版では、動画を止めて書くためのキー（Alt+Shift+C）が、Chrome の都合で割り当てられないことがありました。そのときは「ショートカットを設定してください」と案内を出していました。

使う側に回ってみると、これは作り手の都合を使う人に渡しているだけでした。動画を見ている最中に、設定画面へ行きたい人はいません。開発チームには「設定してください、は無責任な方法だ」と伝え、入れた直後から、設定なしで効くように作り直してもらいました。

「手元の動画ファイルと、変わらない触り心地に」

手元の動画ファイルを開く画面は、C で止めて書き、Enter で再生が続き、, と . で1コマ送れました。ところが YouTube の動画では、止めるたびに別のタブが開き、書き終えると動画に戻る、という流れでした。同じ「動画に指示を書く」なのに、手ざわりが違います。

そこで、ブラウザの動画にも修正モードを作りました。いちど使うと動画の下に帯が出て、C・D・, .・Space が手元の動画と同じに効きます。別のタブは開きません。どちらで覚えても、もう片方でそのまま使える。通して1回見ながら、C と Enter をくり返すだけで指示がたまります。

「説明が多すぎて使う気になりません」

サイドパネルの「修正」には、「1 何を直す？ → 2 撮って書く → 3 伝える」と、手順と説明を丁寧に並べていました。作っているときは親切のつもりでした。

使ってみると、読む前に閉じたくなりました。説明が多い画面は、それだけで「むずかしそう」に見えます。いまの「修正」は、見ているタブに合わせたボタンが1つ、大きく出るだけです。動画があれば「この動画に修正指示」、なければ「このページに修正指示」。手順は「使い方」のボタンの中に移しました。

「上の面積を、取りすぎている」

メニューを上に横並びにしたとき、アイコンの下に名前を置いていたので、上だけで 88px を使っていました。サイドパネルは幅も高さも限られています。メニューに場所を取られると、肝心のタブやブックマークが見えません。

アイコンの横に名前を並べて、88px を 50px に詰めました。あわせて、端に縦並びのときと数が合っていなかったメニューを、同じ10個にそろえました。

使いながら足したもの

  • 保存の知らせ：Enter のあと「✓ 00:07 を指示シートに保存しました」と出る。保存できたかが不安にならないように
  • ゴミ箱：消した指示は30日戻せる。試しに書いたものを、安心して消せるように
  • 「画像はどこにある？」：撮った画像がこのパソコンの中にあり、どこにも送っていないことを、画面で読めるように
  • 「終わる」ボタン：手元の動画の画面に、終わったあとの戻り先を
  • 再生位置の表示：時間・フレーム数・分:秒:フレーム から選べるように。編集する人の数え方で渡せます

あわせて直した不具合

起きていたこと直したこと
ダッシュボードの検索で、グループやブックマークのフォルダが名前で見つからなかったグループ・サブグループ・フォルダも出す。上に「○○の検索結果」と件数を出す
ダッシュボードが瞬く。作業のたびに落ち着かない裏で作ってから一度に入れ替える。中身が変わったときだけ描き直す
ブックマークのフォルダを移すとき、途中の姿が何度も出た終わってから1回だけ描く
ボードの「開いているタブ」の数が、サイドパネルと合わなかった開いているタブをすべて並べ、数も合わせた
2段にしたとき、下の段を左右に送れなかったホイールで送れる。左右に送るボタンも付けた
バンクの名前を書き始めると、すぐ閉じた書いている間は作り直さない
グループの「…」メニューが、すぐ消えることがあった開いている間は描き直さない

瞬きの原因は、ひとつではありませんでした。「先に空にしてから中身を待つ」「打つたびに描き直す」「保存のたびに同じ内容を二度描く」。どれも1つずつは小さなことですが、重なると「ちゃんと動いているのか不安」になります。検索も同じで、結果が出ていても、落ち着かない画面では信じられません。道具は、正しく動くだけでなく、落ち着いて見えることも大事だと学びました。

【実体験】出す前に、自分の仕事で使う

私たちは映像制作の会社です。動画の修正指示は、毎日の仕事そのものです。だから、機能ができたら、まず自分の案件で使います。この日に出た言葉は、どれも使っている最中の、そのままの感想でした。

作り直した形で、実際の案件の修正指示を書きました。これまでの3倍は早く終わりました。流れるように、指示を書けます。プレイヤーがそのままあるので、戻すのも送るのも、その場でできます。直したい所には番号の印を置けるので、指示の文を右側に書いても、同じ番号でどの所の話かすぐにわかります。絵の上に図形で直接書けるので、PowerPoint のようにも使えます。

仕様書の上では、最初の形で完成していました。それでも、使ってみて「使う気になりません」と感じたものを、そのまま出すわけにはいきません。準備を使う人に渡さない。説明で埋めない。場所を取りすぎない。この3つは、次の機能を作るときにも守ります。

知っておきたいこと

  • 版の番号：修正指示そのものは 3.0.4 から。ボタン1つの「修正」の画面、再生位置の表示の切り替え、ダッシュボードの検索と瞬き・ボードのタブの数・2段表示の直しは 3.0.5 から
  • 権限：3.0.3 から、権限の警告は変わりません。新しく外に送るデータもありません
  • プラン：修正指示は PRO の機能です。お試し期間中はすべて使えます。不具合の修正は、どなたにも入ります
  • お試しの終わり：残り7日・3日・1日に、お知らせが出るようになりました。お試しが終わっても、保存したものは何も消えません

前の版の記録は「【開発ストーリー】3.0.3 を作った1日」にあります。

🎬 3.0.5 のほかにも、いろいろできます。パネルを開く、保存したタブを開く、閉じたタブを履歴から戻す、ページにひもづけたメモ、ピンバーまで。ブラウザとパネルの動きをそのまま見られる 操作ガイド（動く画面で見る10の操作） にまとめています。入れたばかりの方は クイックチュートリアル（5分） からどうぞ。

よくある質問

Q. 3.0.4 と 3.0.5 では何が新しくなりましたか？

3.0.4 で、動画や Web ページに番号つきの指示を書く「修正指示」が入りました。動画は、止める → 書く → Enter で保存して再生が続きます。3.0.5 では、「修正」の画面をボタン1つにし、再生位置の表示を選べるようにし、ダッシュボードの検索と瞬き、ボードのタブの数、2段表示の下の段などを直しました。

Q. 3.0.4 と 3.0.5 の違いは何ですか？

修正指示は 3.0.4 から使えます。3.0.5 は、使ってみてまだ重いと感じた所（説明の多い「修正」の画面など）を直し、再生位置の表示の切り替えと、ダッシュボードまわりの不具合の修正を足した版です。

Q. 更新で、権限は増えますか？

権限の警告は 3.0.3 から変わりません。新しく外部に送るデータもありません。撮った画像と指示は、このパソコンのブラウザの中に保存します。

Q. 修正指示は無料で使えますか？

PRO の機能です。お試し期間中はすべて使えます。PRO は買い切りで、月額はありません。
