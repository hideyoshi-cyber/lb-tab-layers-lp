Chrome を再起動したら
タブが消えたときは

2026.10.09 · Liquid Block Inc. · 読了 6分

ポストシェアLINE送るB!ブックマーク

再起動のあとタブが消えていたら、まずは新しいタブをあれこれ開かずに、Ctrl+Shift+T（Macは ⌘+Shift+T）を押してみてください。前のウィンドウがまとめて戻ることがあります。戻らなければ、右上の︙ →「履歴」の「最近閉じたタブ」、それでもなければ Ctrl+H の履歴ページで探します。別のプロフィールやウィンドウを見ているだけ、ということもあるので、そこも確かめます。次から困らないためには、大事なタブをブックマークに保存しておくのがいちばん確実です。

Chrome のアップデートで再起動した、PC を再起動した、Chrome が固まって閉じた。もう一度開いたら、さっきまでのタブが1つもない——。

消えたタブの戻し方は「PC再起動でタブが全部消えたときの復元方法」でも紹介しました。この記事では、「どんなふうに消えているか」から、何をどの順番で確かめればいいかをまとめます。

最初に：あわてて新しいタブを開かない

タブが消えていると、つい検索して開き直したくなります。でも、少しだけ待ってください。

  • 新しいタブを開いたり閉じたりすると、「最近閉じたタブ」の一覧が新しい操作で埋まって、前のウィンドウを探しにくくなります
  • Chrome をもう一度終了して開き直すと、「前回の状態」が今の空っぽの状態に置きかわることがあります

まずは今の画面のまま、次の順番で確かめていきます。

症状1：新しいタブが1つだけ出ている

Chrome が正しく終了しなかったときは、起動した直後に、画面の右上へ「復元」ボタンのある案内が出ることがあります。出ていたら、まずはそれを押してください。前回のタブがまとめて戻ります。案内が出ていない、またはもう消してしまった場合は、次の順番で試します。

1

Ctrl+Shift+T を押す

Ctrl+Shift+T（Macは ⌘+Shift+T）を押します。前回のウィンドウが、中のタブごと戻ることがあります。戻ったら、それ以上押す必要はありません（→「閉じたタブを元に戻すショートカット」）。

2

︙ →「履歴」の「最近閉じたタブ」を見る

右上の︙ →「履歴」を開くと、最近閉じたタブとウィンドウが並んでいます。「〇個のタブ」のようにウィンドウ単位で出ていれば、それを押すとまとめて戻ります。

3

履歴ページで探す

それでも見つからなければ、Ctrl+H（Macは ⌘+Y）で履歴ページを開きます。日付ごとに見たページが並んでいるので、上の検索欄でサイト名やタイトルの一部を入れて探します。1つずつ開き直すことになりますが、ページそのものは見つかります。

症状2：タブはあるのに、さっきと違う

消えたのではなく、別のところを見ているだけのこともあります。

  • 別のウィンドウに戻っている — 複数のウィンドウを開いていた場合、戻ったウィンドウが画面の後ろに隠れていることがあります。Windows はタスクバーの Chrome のアイコンにカーソルを当てる、Mac は Dock の Chrome のアイコンを右クリックすると、開いているウィンドウを確かめられます
  • 別のプロフィールで開いている — 仕事用と個人用など、Chrome のプロフィールを分けている場合、再起動のあと別のプロフィールが開くことがあります。右上のプロフィールのアイコンで、どれを開いているか確かめます（→「Chrome のプロフィール活用術」）
  • シークレットウィンドウだった — シークレットウィンドウのタブは、閉じると戻せません。履歴にも残りません

アップデートのあとだけ消えた場合

Chrome やパソコンのアップデートのあと、一度だけ消えたなら、上の3つの手順でたいてい見つかります。アップデートの再起動は予告されることが多いので、「再起動してください」と出たら、その前に大事なタブを保存しておくと安心です。

症状3：毎回、再起動のたびに消える

一度だけでなく毎回消えるなら、設定を見直します。

1

起動時の設定を確かめる

Chrome の設定 →「起動時」を開き、「前回開いていたページを開く」になっているか確かめます。「新しいタブ ページを開く」のままだと、再起動のたびに新しいタブだけが出ます（→「Chrome の起動時の設定」）。

2

終わるときは Chrome を普通に閉じる

「前回の状態」は、Chrome が正しく終了したときに残るものです。電源ボタンの長押しや、固まったままの再起動が続くと、うまく戻らないことがあります。アップデートの再起動は、Chrome の「再起動」ボタンから行うと、そのまま戻りやすくなります。

3

拡張機能を疑ってみる

タブを自動で閉じたり、まとめたりする拡張機能を入れていると、その動きでタブが減ることがあります。心当たりがあれば、いったん「オフ」にして様子を見ます。

LB TAB Layers を使っていた場合

LB TAB Layers のグループに保存していたタブは、Chrome のブックマークに残っています。再起動でタブが閉じても、保存は消えません。

  • グループの ▶ で開き直す — Alt+T（Macは Option+T）でパネルを開き、使っていたグループの ▶ を押せば、保存したタブがまとめて開きます
  • グループが見当たらないとき — まず、いつものプロフィールを開いているか確かめます。ブックマークマネージャー（Ctrl+Shift+O）に「LB TAB Layers」フォルダが残っていれば、パネルを開いたときにグループとして読み込まれます
  • 今日見たページを探す — PRO版とトライアル中は、パネルの「本日の履歴」から今日開いたページを探せます

どのグループにも入れていなかったタブ（単独タブ）は、保存されていないので、上の Chrome の手順で探してください。

次から困らないための準備

Chrome の復元は便利ですが、「戻るかどうかは、終わり方しだい」です。何日も使うタブは、復元に頼らず保存しておくのが確実です。

  • 大事なタブは、閉じる前にブックマークに保存する — Chrome の一時的なデータではなく、ブックマークに残しておけば、再起動でも強制終了でも消えません（→「セッション保存とブックマーク保存、どちらが安全？」）
  • 仕事の区切りで保存する — LB TAB Layers なら、タブをグループにドラッグするだけで保存されます。終業時にグループの ■ で閉じておけば、翌朝は ▶ ひとつで戻れます
  • ときどきバックアップ — ブックマークのエクスポートや、LB TAB Layers の「エクスポート (JSON)」で、ファイルにも残しておきます

「消えたかもしれない」と探しまわる時間は、本来いらない時間です。保存しておけば、再起動のたびに身構えなくて済みます。

よくある質問

Q. Chrome を再起動したらタブが消えました。まず何をすればいいですか？

新しいタブを開いたり Chrome を閉じ直したりせずに、Ctrl+Shift+T（Macは ⌘+Shift+T）を押してください。前回のウィンドウがまとめて戻ることがあります。戻らなければ、︙ →「履歴」の「最近閉じたタブ」、Ctrl+H の履歴ページの順に探します。

Q. 「前回開いていたページを開く」にしているのに、タブが戻りません。

Chrome が正しく終了しなかった場合（強制終了、電源の長押し、固まったままの再起動など）は、うまく戻らないことがあります。別のウィンドウやプロフィールを開いているだけのこともあるので、そちらも確かめてください。

Q. シークレットウィンドウのタブは戻せますか？

戻せません。シークレットウィンドウは閉じると履歴も残らないためです。

Q. LB TAB Layers に保存したタブは、再起動で消えますか？

消えません。グループに保存したタブは Chrome のブックマークに残っているので、パネルを開いてグループの ▶ を押せば、まとめて開き直せます。
