毎朝使うタブを
1クリックでまとめて開く

2026.10.19（2026.11.09 更新） · 執筆：蔡本 英賛（株式会社リキッドブロック 代表） · 読了 6分

ポストシェアLINE送るB!ブックマーク

毎朝のタブをまとめて開く方法は、大きく3つあります。Chrome の起動時の設定で決まったページを開く方法、ブックマークのフォルダからまとめて開く方法、LB TAB Layers で「毎朝」のグループを作って ▶ で開く方法です。▶ は、まだ開いていないページだけを開き、同じ名前・同じ色の Chrome のタブグループにまとめます。終わったら ■ でまとめて閉じられます。

朝、パソコンを開いたら、まずメール。次にカレンダー、チャット、勤怠の打刻。毎日同じページを、1つずつ開いていないでしょうか。

1回は数秒でも、毎日くり返すと積み重なります。開き忘れた画面に大事な連絡が来ていた、ということも起きます。この記事では、毎朝のタブを「セット」にして、1クリックでまとめて開く方法を3つ比べます。

動く画面で見る：▶ で開いて、■ で閉じる

LB TAB Layers では、グループの ▶ を押すと、中のページがまとめて開き、グループと同じ名前・同じ色の Chrome のタブグループにまとまります。■ を押すと、そのタブグループごと閉じます。保存はそのまま残ります。

タブを仕事ごとにまとめて、▶ で開いて ■ で閉じる。

LB TAB Layers は、開いているタブを仕事ごとに Chrome のブックマークへ保存し、▶ ひとつで同じ名前・色のタブグループとして開き直せる、サイドパネルの拡張機能です。閉じても消えません。

Chrome に無料で追加動く画面で見る →

まず、朝のセットに入れるページを決める

最初に、毎朝ほぼ必ず開くページを書き出します。多くの人は、5〜8枚くらいに収まります。

種類例
連絡メール、チャット（Slack・Teams・Chatwork など）
予定カレンダー、会議室の予約
社内の手続き勤怠の打刻、経費の申請、社内ポータル
今日の仕事タスク管理、共有のスプレッドシート

コツは「毎日」開くものだけにすることです。週に1回しか見ない画面まで入れると、朝からタブが増えすぎます。たまに見る画面は、別のセットに分けておきます。

方法1：Chrome の起動時に、決まったページを開く

Chrome の「設定」→「起動時」で「特定のページまたはページセットを開く」を選び、メールやカレンダーのアドレスを入れておく方法です。

向いている人：朝いちばんに Chrome を起動して、毎日まったく同じページを開く人。何も押さなくても開くのがいちばんの長所です。

気をつけること：起動のたびに開くので、再起動したときにも同じページが開きます。また、この設定にすると、前回開いていたタブは自動では戻りません。くわしくは「Chrome 起動時の設定ガイド」にまとめています。

方法2：ブックマークのフォルダを、まとめて開く

ブックマークに「毎朝」のフォルダを作って毎朝のページを入れ、朝はフォルダを右クリックして、中のページをまとめて開く方法です。

向いている人：拡張機能を入れずに済ませたい人。起動のときだけでなく、好きなときに開けるのが方法1との違いです。

気をつけること：すでに開いているページも、もう一度開きます。中身を入れ替えるときは、ブックマークの管理画面で動かします。

方法3：LB TAB Layers の「毎朝」グループと ▶

LB TAB Layers のグループは、そのまま Chrome のブックマークのフォルダとして保存されます。方法2と同じ考え方ですが、開く・閉じる・中身を変えるが、サイドパネルの中で済みます。

1

「毎朝」のグループを作る

Alt+T（Mac は Option+T）でパネルを開き、右の列の「ブックマーク」を選びます。一覧の一番上の「＋ 新しいグループ」を押して、「毎朝」という名前で作ります。カレンダーのアイコンを選んでおくと、一覧で見つけやすくなります。

2

毎朝のページを入れる

メールやカレンダーのページを開いた状態で、パネルの下の「現在のタブを追加」を押し、保存先に「毎朝」を選びます。ページの上で右クリック →「TAB Layers に保存」からでも入れられます。

3

朝は ▶ を押す

「毎朝」グループの ▶ を押すと、中のページがまとめて開きます。グループの名前を押したときは、中の一覧が開いたり畳んだりするだけです。

▶ には、うれしいところが3つあります。

  • すでに開いているページは、二重に開きません。メールだけ先に開いていても、足りないページだけが開きます。全部開いていれば「すべて開いています」と出ます
  • 今見ている画面は切り替わりません。タブは裏で開くので、読んでいるページはそのままです
  • Chrome のタブグループにまとまります。タブバーの上で「毎朝」のタブがひとかたまりになり、ほかのタブと混ざりません

▶ と ■ のくわしい動きは「Chromeのタブグループを自動で作る・まとめて閉じる」にまとめました。

1枚だけ開きたいときは、タブを押す

グループの名前を押すと、中の保存したタブが並びます。タブを押すと、そのページが開きます。もう開いているタブは、押すとそのタブに切り替わるので、同じページが2枚になりません。

こんなふうに使うと便利

曜日や月末で、セットを分ける

毎朝のページは、ずっと同じとは限りません。セットを増やしても、押すのは ▶ だけです。

グループ中身押すとき
毎朝メール・カレンダー・チャット・勤怠毎日の始業
月曜週の予定表・先週の数字月曜の朝だけ
月末経費の申請・請求書の一覧月末の数日

帰るときは ■ で片づける

仕事が終わったら、■ を押すだけ。「毎朝」のタブグループがまとめて閉じます。そのタブグループの中に、保存していないタブが混ざっているときは、一緒に閉じてよいか聞いてくれます。

連絡用のウィンドウを分ける

グループの「…」→「新しいウィンドウで開く」を選ぶと、別のウィンドウにまとめて開きます。連絡用と作業用でウィンドウを分けたい人に向いています。

知っておきたいこと

  • タブグループにしたくないときは、設定で切れます。設定の「まとめて開くとき、Chrome のタブグループにする」をオフにすると、▶ はタブを開くだけになります
  • 入れたページを外すときは、行のゴミ箱のボタン。ブックマークのゴミ箱へ移り、8秒間「元に戻す」が出ます
  • 開き忘れを防ぐなら「チラ見せ」。Chrome を起動したときに LB TAB Layers が少しのあいだ出てくるので、▶ を押し忘れません（PRO と試用期間中）。くわしくは「起動時にサイドバーを自動で開く方法」へ

ℹ️ 無料版でもグループは5つまで作れて、▶ と ■ も使えます。「毎朝」「月曜」「月末」に、今の仕事を2つ足しても収まります。インストールから90日間の試用期間は、すべての機能を使えます。

🎬 まとめて開くほかにも、いろいろできます。パネルを開く、保存したタブを開く、閉じたタブを履歴から戻す、ページにひもづけたメモ、ピンバーまで。ブラウザとパネルの動きをそのまま見られる 操作ガイド（動く画面で見る10の操作） にまとめています。入れたばかりの方は クイックチュートリアル（5分） からどうぞ。

よくある質問

Q. Chrome だけで、複数のタブをまとめて開けますか？

開けます。設定の「起動時」で決まったページを開くようにすると、起動のたびに開きます。好きなときに開きたいなら、ブックマークのフォルダからまとめて開く方法があります。

Q. LB TAB Layers でグループの名前を押しても、タブが開きません。

グループの名前を押したときは、中の一覧が開いたり畳んだりするだけです。まとめて開くときは、グループの右の ▶ を押してください。1枚だけ開くときは、中のタブを押します。

Q. ▶ を押したら、すでに開いているメールがもう1枚開きますか？

開きません。▶ は、まだ開いていないページだけを開きます。すべて開いているときは「すべて開いています」と出ます。

Q. ▶ で開いたタブは、どうなりますか？

グループと同じ名前・同じ色の Chrome のタブグループにまとまります。■ を押すと、そのタブグループごと閉じます。設定の「まとめて開くとき、Chrome のタブグループにする」をオフにすると、タブグループにはしません。

Q. 無料版でも使えますか？

使えます。無料版でもグループは5つまで作れて、▶ でまとめて開くことも、■ でまとめて閉じることもできます。インストールから90日間は、すべての機能を試せます。
