iPhone のブックマークはどこ？
Safari と Chrome、それぞれの場所。

2026.11.24 · 執筆：蔡本 英賛（株式会社リキッドブロック 代表） · 読了 7分

ポストシェアLINE送るB!ブックマーク

iOS 27 の Safari では、ブックマークは、スタートページにある「ブックマークを表示」ボタン（開いた本の形）から開きます。タブのレイアウトが「下」か「上」の場合は、同じ本の形のボタンをタップするだけです。iPhone の Chrome アプリでは、その他アイコン（…）→［ブックマーク］です。PC の Chrome と同じ Google アカウントで iPhone の Chrome にログインすると、PC のブックマークも iPhone で見られます（2026 年 11 月時点・Apple と Google の公式ヘルプで確認）。

iPhone を新しい iOS にしたら、Safari のブックマークがどこにあるのか分からなくなった。そんなときのために、iPhone のブックマークの場所を、Safari と Chrome に分けてまとめました。

手順とボタンの名前は、Apple の「iPhone ユーザガイド」（iOS 27 版）と、Google Chrome ヘルプ（iPhone と iPad）に書いてあるとおりです（2026 年 11 月時点）。画面は iOS やアプリの版で変わります。違って見えるときは、記事の終わりの参考リンクから公式ページを開き、お使いの版を選んで確かめてください。

iPhone の Safari のブックマークはどこ？（iOS 27）

iOS 27 の Safari では、ブックマークは「ブックマークを表示」ボタン（開いた本の形）から開きます。開き方は 2 つあります。

開き方手順
スタートページからスタートページへ移動して、開いた本の形のボタンをタップ
タブのレイアウトが「下」か「上」の場合開いた本の形のボタンをタップ
1

Safari を開く

iPhone で Safari アプリを開きます。

2

スタートページへ移動する

ページを開いているときは、タブボタン（四角が 2 つ重なった形）をタップしてから、追加ボタン（＋）をタップすると、スタートページが 1 つ開きます。

3

「ブックマークを表示」ボタン（開いた本の形）をタップする

ブックマークの画面が開きます。

開くと、画面の上部に、最近保存したブックマーク・お気に入り・リーディングリストの項目が並びます。新しいものが左にあり、スクロールするとほかの項目も見られます。ブックマークを長押しすると、コピー・開く・編集・削除ができます。

Apple Intelligence に対応した機種では、ブックマークやリーディングリストに関連する項目が 3 つ以上あると、候補のトピックごとに自動でまとめて表示されます（一部の言語や地域では使えません）。

タブを仕事ごとにまとめて、▶ で開いて ■ で閉じる。

LB TAB Layers は、開いているタブを仕事ごとに Chrome のブックマークへ保存し、▶ ひとつで同じ名前・色のタブグループとして開き直せる、サイドパネルの拡張機能です。閉じても消えません。

スタートページへ行かずに開きたいときは — タブのレイアウトを「下」か「上」に

スタートページまで行くのが手間なときは、Safari のタブのレイアウトを変えられます。Apple のユーザガイドでは、レイアウトが「下」または「上」の場合は、「ブックマークを表示」ボタンをタップして開く、となっています。

1

設定アプリを開く

Safari の中ではなく、iPhone の「設定」アプリです。

2

「アプリ」→「Safari」をタップする

「アプリ」の中に「Safari」があります。

3

「タブ」まで下にスクロールして、「下」か「上」を選ぶ

選べるレイアウトは、次の 3 つです。

レイアウト画面の形
コンパクトタブバーが小さくまとまって、ページの下に出る。追加のコントロールは、タブバーの両側に出る
下タブバーが広がって、ページの下に出る。追加のコントロールは、画面の下部に出る
上タブバーが広がって、ページの上に出る。追加のコントロールは、画面の下部に出る

「コンパクト」は、機種によっては選べません。

Safari でブックマークを追加する・整理する（iOS 27）

ブックマークに追加する

ブックマークに入れたいページを開き、ページメニューボタン（長さの違う横線が 3 本並んだ形）をタップ →「ブックマークの追加先」→ 場所を選ぶ →「保存」の順です。

タブのレイアウトが「下」または「上」の場合は、「ブックマークを表示」ボタンをタップしてから、「ブックマークを追加」をタップします。

フォルダに分ける・名前を変える・消す

ブックマークの画面で、次の操作ができます。

  • 新しいフォルダを作る — その他ボタン（…）→「新規フォルダ」→ 名前を入力 →「保存」
  • フォルダへ移す — ブックマークを長押し →「編集」→「場所」の下をタップ → フォルダをタップ →「保存」
  • 名前を変える — ブックマークを長押し →「編集」→ 新しい名前を入力 →「保存」
  • 消す — ブックマークを長押し →「削除」
  • 並べ替える — その他ボタン（…）→「ブックマークを選択」→ 並べ替えボタンを長押しして、新しい場所へドラッグ

よく開くページは、ホーム画面にも置ける

ページメニューボタン →「共有」→ リストを下にスクロールして「ホーム画面に追加」→「追加」で、そのページのアイコンをホーム画面に置けます。レイアウトが「下」または「上」の場合は、共有ボタン（四角から上向きの矢印が出た形）からです。このアイコンは、追加した iPhone にだけ表示されます。

iOS 26 の iPhone では、入口が違います

iOS 26 版のユーザガイドでは、同じ操作の入口が違います。iOS 26 から 27 に上げた方は、ここが変わっています。

iOS 26iOS 27
ブックマークを開くその他ボタン →「ブックマーク」スタートページへ移動 →「ブックマークを表示」ボタン
ブックマークに追加するその他ボタン →「ブックマークの追加先」ページメニューボタン →「ブックマークの追加先」
レイアウトが「下」「上」の場合「ブックマークを表示」ボタン「ブックマークを表示」ボタン（同じ）

どちらの版でも、タブのレイアウトが「下」か「上」なら、「ブックマークを表示」ボタンから開けます。もっと前の iOS をお使いの場合は、Apple のユーザガイドのページの上にある「バージョンを選択」で、お使いの版に切り替えて確かめてください。

iPhone の Chrome アプリのブックマークはどこ？

iPhone の Chrome アプリでは、その他アイコン（…）→［ブックマーク］です。

1

Chrome を開く

iPhone で Chrome アプリを開きます。

2

その他アイコン（…）→［ブックマーク］をタップする

［ブックマーク］には、☆ のマークが付いています。

3

フォルダをタップして、ブックマークを開く

新しいタブやシークレット タブで開きたいときは、ブックマークを長押しして、メニューから選びます。

探しているブックマークが見つからないときは、別のフォルダに入っていることがあります。左上の「戻る」をタップして、ほかのフォルダを見てください。

  • 追加する — ページを開いて、その他アイコン（…）→［ブックマークに追加］
  • 直す — ブックマークを長押し →［編集］→ 名前・フォルダ・URL を変えて、画面上部の［完了］
  • 消す — ブックマークを左にスワイプ →［削除］

PC の Chrome と同じブックマークを、iPhone で見る（同期）

PC の Chrome で使っているブックマークは、iPhone の Chrome アプリで、同じ Google アカウントにログインすると、iPhone でも見られます。Google のヘルプでは、Chrome にログインすると Google アカウントに情報を保存でき、同じアカウントでログインしているすべてのデバイスで同じ情報を使える、と説明されています。ブックマークは、その対象に入っています。

1

iPhone で Chrome アプリを開く

入っていない場合は、App Store から入れます。

2

その他アイコン（…）→［設定］→［ログイン］をタップする

［Chrome へのログイン］で、PC の Chrome と同じ Google アカウントを選んで、続けます。

3

その他アイコン（…）→［ブックマーク］を開く

フォルダを順に開いて、PC で使っているブックマークを探します。

出てこないときに確かめること

  • 同じ Google アカウントか — PC の Chrome と iPhone の Chrome で、ログインしているアカウントが同じかを見ます
  • ブックマークを保存する設定か — iPhone は、その他アイコン（…）→［設定］→ 上のアカウント名 で、Google アカウントに保存する情報を選べます。PC は、右上のその他アイコン →［設定］→［Google の設定］→ アカウント名 です
  • ログインする前から入っていたブックマーク — ログアウトしているあいだのブックマークは、そのデバイスの中にだけ保存されます。iPhone は［設定］→ 名前 →［アカウントに保存］、PC は右上のプロファイル →［アカウントに x 件のアイテムを保存］から、アカウントに保存できます
  • 別のフォルダに入っていないか — 左上の「戻る」で、ほかのフォルダも見ます

Google アカウントに保存できるブックマークは、最大 100,000 件です（Google Chrome ヘルプ・2026 年 11 月時点）。PC 側の同期の設定は、Chrome のブックマーク同期ガイドにまとめています。

Safari のブックマークと、Chrome のブックマークは別です

Safari のブックマークは iCloud で、Chrome のブックマークは Google アカウントで、それぞれ別に届きます。やりたいことで、使うものが変わります。

やりたいこと方法
Mac の Safari のブックマークを、iPhone の Safari で見るiPhone の設定アプリ → 自分の名前 →「iCloud」→「すべてを表示」で、「Safari」がオンかを確かめる。Mac も同じ Apple Account でサインインし、iCloud の設定で「Safari」をオンにする
PC の Chrome のブックマークを、iPhone で見るiPhone の Chrome アプリで、PC と同じ Google アカウントにログインする
iPhone の Safari のブックマークを、Chrome に入れる設定アプリ →「アプリ」→「Safari」→「履歴とウェブサイトデータ」の下の「書き出す」でデータを書き出し、Chrome の［設定］→［Safari からのインポート］で読み込む

Safari から書き出したファイルは暗号化されていないので、読み込んだあとは消しておくよう、Apple のページに注意書きがあります。

PC でしまったタブも、iPhone の Chrome で見られます（LB TAB Layers の場合）

ここからは、PC の Chrome で LB TAB Layers を使っている方と、使ってみようかと考えている方への話です。

LB TAB Layers は、PC の Chrome で使う拡張機能です。開いているタブを案件ごとのグループにしまい、▶ でまとめて開き、■ でまとめて閉じます。iPhone では動きません。iPhone に入れて使うものではありません。

ただ、しまったタブの保存先は、Chrome のふつうのブックマークです。Chrome のブックマークの中に「LB TAB Layers」というフォルダができ、グループはフォルダ、しまったタブはブックマークとして入ります（PC では「その他のブックマーク」の中です）。そのため、上の同期をしていれば、iPhone の Chrome の［ブックマーク］にも同じフォルダが届き、しまったページを iPhone で開けます。

  • iPhone で見られるもの — グループ（フォルダ）と、しまったタブ（ブックマーク）。フォルダを順にタップして開きます
  • iPhone では使えないもの — ▶ でまとめて開く・■ でまとめて閉じる といったパネルの操作と、メモ、ステップタスク。メモなどは PC の中だけに保存されるので、同期では届きません

たとえば、PC で「A 社」のグループにしまっておいた資料のページを、出先で iPhone から 1 つ開いて確かめる、という使い方ができます。保存のしくみはブックマーク同期のしくみに、はじめ方はクイックチュートリアルにまとめています。

まとめ

  • Safari（iOS 27） — スタートページにある「ブックマークを表示」ボタン（開いた本の形）から。タブのレイアウトが「下」か「上」なら、そのボタンをタップするだけ
  • レイアウトの変え方 — 設定アプリ →「アプリ」→「Safari」→「タブ」
  • Chrome アプリ — その他アイコン（…）→［ブックマーク］
  • PC の Chrome と同じブックマーク — iPhone の Chrome アプリで、同じ Google アカウントにログインする
  • Safari と Chrome のブックマークは別 — Safari は iCloud、Chrome は Google アカウント

よくある質問

Q. iOS 27 にしたら、Safari のブックマークがどこにあるか分かりません。

スタートページへ移動して、「ブックマークを表示」ボタン（開いた本の形）をタップします。ページを開いているときは、タブボタン → 追加ボタン（＋）でスタートページを 1 つ開けます。設定アプリ →「アプリ」→「Safari」→「タブ」でレイアウトを「下」か「上」にすると、本の形のボタンをタップするだけで開けます（Apple の iPhone ユーザガイド iOS 27 版・2026 年 11 月時点）。

Q. iOS 26 の iPhone では、どこから開きますか？

iOS 26 版のユーザガイドでは、その他ボタン →「ブックマーク」です。タブのレイアウトが「下」か「上」の場合は、「ブックマークを表示」ボタンから開きます。

Q. iPhone の Chrome アプリのブックマークはどこですか？

Chrome を開いて、その他アイコン（…）→［ブックマーク］をタップします。見つからないときは、左上の「戻る」をタップして、別のフォルダを見てください。

Q. PC の Chrome のブックマークを、iPhone でも見られますか？

iPhone の Chrome アプリで、PC と同じ Google アカウントにログインすると見られます。その他アイコン（…）→［設定］→［ログイン］からログインします。Safari のブックマークとは別なので、Chrome アプリの中で開きます。

Q. LB TAB Layers は iPhone で使えますか？

使えません。LB TAB Layers は PC の Chrome で使う拡張機能です。ただし、しまったタブは Chrome のブックマークの「LB TAB Layers」フォルダに入るので、Chrome の同期をしていれば、iPhone の Chrome のブックマークから開けます。メモやステップタスクは PC の中だけに保存され、iPhone には届きません。
