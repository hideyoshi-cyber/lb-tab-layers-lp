2026.08.18 · Liquid Block Inc. · 読了 6分

マウスでタブをクリックして切り替え、右クリックして閉じる——。
その操作、キーボードショートカットなら1秒で終わります。

この記事では、Chromeのタブ操作に関するショートカットをWindows / Mac 両対応で完全網羅します。

覚えるべきベスト5

全部覚える必要はありません。この5つだけで日常のタブ操作が劇的に変わります。

1

Ctrl + T — 新規タブ

何かを検索したいとき、マウスで＋ボタンを押す必要なし。最も使用頻度が高いショートカットです。

2

Ctrl + W — タブを閉じる

見終わったタブを即座にクローズ。右クリック→閉じるの手順が不要に。

3

Ctrl + Shift + T — 閉じたタブを復元

間違えて閉じてしまったタブを復活。連打すれば何個前でも遡れます。履歴から探す手間がゼロに。

4

Ctrl + Tab — 次のタブへ

タブバーをクリックせずに隣のタブへ瞬時に移動。Alt+Tabのタブ版です。

5

Ctrl + 1〜9 — N番目のタブへ

Gmail(1番目)・Slack(2番目)など、固定タブへの移動に最適。

ショートカットでも解決しない問題

ショートカットはタブ操作を速くしますが、タブが50個、100個になると根本的な問題が残ります。

  • Ctrl + 1〜9 は最大9番目まで。10個以降はマウス操作が必要
  • タブが多すぎるとタイトルが見えず、どのタブか判別できない
  • PC再起動でショートカットでは復元できない

ショートカットで「速く操作する」ことと、タブ管理で「整理する」ことは別の問題です。
