ブックマークとメモを
上下に並べて作業する

2026.11.01 · Liquid Block Inc. · 読了 7分

ポストシェアLINE送るB!ブックマーク

LB TAB Layers の切替バーで「統合」を押し、下の欄の「メモ」を開くと、上に保存したページ（グループ一覧）、下にメモが並びます。資料のページを開きながら、会議の宿題や調べてわかったことを書けて、上下の広さも境目のドラッグで変えられます。終わったらメモを Markdown 形式でコピーして、チャットや議事録に貼れます。統合レイアウトもメモも無料版で使えます。

Web 会議で資料のページを開きながら、決まったことをメモする。調べものをしながら、見つけたページを残し、わかったことを書きとめる。どちらも「ページの一覧」と「メモ」を何度も行き来する作業です。

この2つが別々の場所にあると、切り替えるたびに「どこまで書いたっけ」「あのページはどこだっけ」と手が止まります。この記事では、1つのサイドパネルに上下で並べて、行き来を減らす方法を紹介します。

Chrome の標準機能だけでやると

Chrome のサイドパネルにはブックマークを表示できるので、保存したページを横に出しておくことはできます（→ サイドパネルでブックマークを表示する方法）。ただ、Chrome ヘルプで案内されている標準の項目には、メモを書く機能はありません。メモはドキュメントやメモアプリを別のタブ・ウィンドウで開いて書くことになり、ページとメモの間を行き来する手間は残ります。

「統合」レイアウトなら、上にページ・下にメモ

LB TAB Layers v2.9.0 では、上部のモードが「タブ」のとき、その下に「タブ」「ブックマーク」「統合」「メモ」の切替バーが表示されます。このうち「統合」は、1つの画面を上下に分けるレイアウトです。

場所表示されるもの
上グループ一覧（保存したページ。中身は Chrome のブックマーク）
下の欄「単独タブ」「本日の履歴」「メモ」をタブで切り替え

下の欄で「メモ」を選ぶと、上でグループのページを開きながら、下でメモを書けます。ほかの「タブ」「ブックマーク」「メモ」のボタンは、それぞれを高さいっぱいに表示する「切り分け」の画面です。1つのことに集中したいときは切り分け、並べて使いたいときは統合、と使い分けます。

設定の手順

1

パネルを開いて「統合」を押す

Alt+T（Mac は Option+T）で LB TAB Layers を開き、切替バーの「統合」を押します。「統合レイアウト（1画面表示）に変更しました」と表示されれば切り替わっています。

2

下の欄で「メモ」を選ぶ

下の欄のタブ（「単独タブ」「本日の履歴」「メモ」）で「メモ」を押します。

3

広さを決める

上下の境目にあるハンドルを上下にドラッグして、グループ一覧とメモの広さを決めます。変えた広さは保存され、次に開いたときも同じ広さで表示されます。

4

作業用のメモを作る

「☑ チェックリスト」か「＋ メモを入力…」で、この作業用のメモを作ります。タイトルを付けて、カード右上のピンで固定しておくと、メモが増えても一番上に出ます。

💡 下の欄は、パネルを開き直すと「単独タブ」の表示から始まります。メモを書くときは、下の欄の「メモ」をもう一度押してください。グループ一覧だけを広く見たいときは、下の欄の右端にあるボタン（この欄を折りたたむ）で、下の欄をたたむこともできます。

Web 会議で使う

会議の前：資料を1つのグループに

議題のドキュメント、共有する資料、会議の URL を1つのグループに保存しておきます。会議の前にグループの ▶ を押せば、まとめて開けます（→ Web会議の直前にもたつかない方法）。

会議中：議題をチェックリストに

下の欄のメモに、議題をチェックリストで並べておきます。話し終わった議題からチェックを入れると「完了したアイテム」に移るので、残りの議題がひと目でわかり、時間の配分を考えやすくなります。決まったことや宿題は、別のテキストのメモに書いていきます。

話の途中で資料を見たくなったら、上のグループ一覧でそのページを押します（グループ名を押すと、中のページが表示されます）。開いていればそのタブに切り替わり、閉じていれば新しいタブで開きます。

会議のあと：メモをコピーして共有

カードの「コピー」を押すと、タイトルが見出し（###）、チェックリストが「- [ ]」「- [x]」の形でコピーされます。チャットや議事録のドキュメントにそのまま貼れます。

コピーされるテキストの例：

### 定例の宿題
- [x] 公開日を決める
- [ ] 見積の修正版を送る（担当：田中）
- [ ] 次回の日程を調整する

メモは、このパソコンの Chrome の中（拡張機能の保存領域）に保存されます。ほかのパソコンとは同期されず、拡張機能を削除するとメモも消えます。残しておきたい会議のメモは、コピーして議事録やチャットに貼るか、「テキスト保存 (.txt)」でファイルにしておきましょう。

⚠️ 画面全体やウィンドウを共有していると、サイドパネルのメモも相手に見えることがあります。見せたくないメモがあるときは、共有する範囲をタブだけにするなど、会議の前に確かめておきましょう。

調べもので使う

見つけたページは上のグループへ

調べものの名前でグループを作っておきます。役に立つページを見つけたら、下の欄を「単独タブ」に切り替えて、そのタブを上のグループへドラッグすると保存できます。ページの上で右クリックして「TAB Layers に保存」を選ぶ方法もあります（→ タブを保存する3つの方法）。保存したページは Chrome のブックマークになるので、タブを閉じても残ります。

わかったことは下のメモへ

下の欄を「メモ」に戻して、わかったことを書きます。「確かめること」をチェックリストにしておき、答えが見つかったらチェックする使い方もおすすめです。保存したページそのものに「なぜ残したか」を書いておきたいときは、ページごとのひとことメモ（右クリック →「メモを編集」）が向いています（→ メモ機能）。

まとめるときは、両方を見ながら

最後に報告やレポートを書くときは、上のグループで出典のページを開き、下のメモでわかったことを確かめながら進めます。グループのリンク集は「Markdown形式でコピー」でまとめてコピーできるので、メモのコピーと合わせて貼れば、出典つきのメモになります（→ Markdown形式でコピー）。

もっと広く使いたいとき

  • 切り分けで交互に見る — 「ブックマーク」と「メモ」を、それぞれ高さいっぱいの画面で切り替えて使えます。切替バーのボタンはドラッグで並べ替えられるので、「ブックマーク」と「メモ」を隣どうしにしておくと行き来が楽です。
  • 独立ウィンドウ（別窓）で開く — ヘッダー右上（時計アイコンの右隣）のボタンから「独立ウィンドウ（別窓）で開く」を選ぶと、パネルを小さなウィンドウで開けます。2台目のモニターに置いて、統合レイアウトでページの一覧とメモを並べておく使い方もできます。

統合レイアウト・メモ・別窓は、どれも無料版で使えます。下の欄の「本日の履歴」は PRO版とトライアル中の機能です。

ページとメモが同じ場所にあれば、「どこだっけ」と探す時間が減ります。会議の中身や調べものの答えに、頭を使えるようになります。

よくある質問

Q. 下のメモ欄の広さは変えられますか？

変えられます。「統合」レイアウトで、グループ一覧と下の欄の境目にあるハンドルを上下にドラッグします。変えた広さは保存されます。切り分けの画面では、ハンドルと折りたたみは表示されません。

Q. パネルを開き直すと、下の欄がメモではなくなります。

下の欄は、パネルを開くたびに「単独タブ」の表示から始まります。メモを書くときは、下の欄の「メモ」を押してください。メモの内容は保存されているので、続きから書けます。

Q. 会議のメモを議事録やチャットに貼るには？

カードの「コピー」を押します。タイトルが「###」の見出し、チェックリストが「- [ ]」「- [x]」の形でコピーされるので、そのまま貼れます。ファイルで渡したいときは「テキスト保存 (.txt)」を使います。

Q. 無料版でも使えますか？

統合レイアウトとメモは無料版で使えます。下の欄の「本日の履歴」は PRO版とトライアル中の機能です。無料版のグループは5つまで（サブグループも数に入ります）です。
