Chrome の縦タブを元に戻す方法
横に戻す・出てこない時・設定の場所

2026.11.24 · 執筆：蔡本 英賛（株式会社リキッドブロック 代表） · 読了 6分

Chrome の縦タブ（垂直タブ）を元に戻すには、縦に並んだタブか、タブバーの空白を右クリックして［タブを横方向に表示］を選びます。設定からなら、［設定］→［デザイン］→［タブの位置］で［横］を選びます。「タブを縦方向に表示」がメニューに出てこないときは、右上の ︙ →［ヘルプ］→［Google Chrome について］で Chrome を最新にしてから、もう一度確かめます（Google Chrome ヘルプの手順・2026 年 11 月時点）。

Chrome の縦タブ（タブを縦方向に表示）は、2026 年 4 月から順に提供が始まった機能です。試してみたけれど横のほうが合っていた。気づいたら縦になっていた。使いたいのにメニューに出てこない。この記事では、そんな「困ったとき」の答えを、Google の公式ヘルプの手順をもとにまとめます。

オンにする方法や、縦タブでできることは「Chrome の縦タブの使い方 — できること・できないこと」にまとめています。

Chrome の縦タブを横に戻す方法

戻す入口は 5 つあります。どれを使っても、結果は同じです。

縦に並んだタブタブを右クリック →［タブを横方向に表示］

［タブを縦方向に表示］は、タブを右クリックしたメニューに入っています。気づかないうちに選んでいて、いつの間にか縦になっていた、ということもあります。その場合も、同じメニューから戻せます。

切り替えで変わるのは、タブバーの場所です。公式ヘルプは、縦タブを「タブバーがウィンドウの横に移動する」表示と説明しています。

  2. 左の［デザイン］を選ぶ
  3. ［タブの位置］で［横］を選ぶ（縦にしたいときは［縦］）

縦タブの設定の場所は、［設定］→［デザイン］

縦タブに関わる設定は、［設定］の［デザイン］に集まっています。

項目の名前は、2026 年 11 月 23 日に Chrome 157 の画面で確かめた表記です（Google Chrome ヘルプでは、タブグループの項目が「保存したタブグループを表示する」と書かれています）。Chrome の版によって、画面の言葉が少し違うことがあります。そのときは、［デザイン］の中で近い言葉を探してください。

縦タブが表示されない・メニューに出てこないとき

右クリックしても［タブを縦方向に表示］が出てこないときは、次の順に確かめます。

1. Chrome を最新にする

縦タブは、Google が 2026 年 4 月 7 日に提供の開始を発表した機能です。管理者向けのリリースノートには、Windows・Mac・Linux は Chrome 147 から、ChromeOS は Chrome 148 から、順に提供すると書かれています。それより前の版には、公式の機能としては入っていません。

  1. 右上の ︙（その他）→［ヘルプ］→［Google Chrome について］を開く。見出しの下の番号が、今の版です。このページを開くと、更新があるかどうかも確かめられます
  2. ［再起動］が出ていたら、押す。出ていなければ、最新の版です

開いていたタブやウィンドウは、再起動のあとで自動的に表示されます（シークレット ウィンドウは表示されません）。Linux はパッケージ マネージャで、Chromebook は本体のシステム（OS）の更新で、Chrome が新しくなります。

2. 右クリックのほかの入口を使う

公式ヘルプの手順は、タブバーの空白か、タブの上での右クリックです。うまく出ないときは、ほかの入口から選びます。

  • 右上の ︙（その他）→［その他のツール］→［タブを縦方向に表示］
  • ［設定］→［デザイン］→［タブの位置］で［縦］
  • Mac なら、画面の上のメニューの［表示］→［タブを縦方向に表示］

3. パソコンの Chrome かどうか

縦タブの手順は、公式ヘルプの「パソコン」向けの説明に載っています。Android と iPhone・iPad 向けの説明には、2026 年 11 月時点で縦タブの項目は載っていません。

4. 会社や学校のパソコンの場合

職場や学校の Chrome は、組織が設定を管理していることがあります。公式ヘルプによると、その場合は、管理者が特定の機能を設定したり制限したりしている可能性があります。

  • 右上の ︙ のメニューの下のほうに「組織によって管理されています」と出ていれば、管理されている Chrome です
  • アドレスバーに chrome://management と入力して Enter キーを押しても、確かめられます

管理されている Chrome で、更新しても出てこないときは、社内や学校の管理者に聞くのが早道です。

5.「chrome://flags から有効にする」という手順を見かけたら

2026 年 11 月時点の公式ヘルプに、その手順は載っていません。公式の入口は、右クリック・︙ のメニュー・設定・Mac の［表示］メニューです。まず Chrome を最新にして、こちらの入口を確かめてください。

縦タブは左右どちらに出る？ 右側に出したいとき

公式ヘルプの説明は「タブバーがウィンドウの横に移動する」で、左右を選ぶ手順は載っていません（2026 年 11 月時点）。［タブの位置］で選べると書かれているのは、［縦］と［横］の 2 つです。

当社で Chrome 157 の［設定］→［デザイン］を確かめたところ、［タブの位置］で選べるのは［縦］と［横］で、左右を選ぶ項目はありませんでした（2026 年 11 月 23 日）。

一方、サイドパネルは左右を選べます。［設定］→［デザイン］の［サイドパネルの位置］で、どちら側に開くかを選びます。縦タブと同じ側にサイドパネルが出て窮屈なときは、サイドパネルを反対側に移すと、左右に分かれます。サイドパネルの幅は、パネルの端をドラッグして変えられます。サイドパネルの出し方や左右の変え方は「Chrome のサイドバー（サイドパネル）完全ガイド」にまとめています。

横に戻す前に試せること — 縦タブで困ったとき

「縦は見やすいけれど、ここが困る」というときは、戻す前に次のことを試せます。

横幅を取りすぎる

縦のタブバーは、幅を変えられます。たたんで細くした表示もあり、その状態でタブにカーソルを合わせると、タブグループの名前やページの題名が広がって見えます。

カーソルを合わせると広がるのが気になる

たたんだ表示でカーソルを合わせたときに広がる動きは、オンとオフを選べます。公式ヘルプの手順は、「メニューを開く」アイコンを右クリック →［折りたたまれたタブにカーソルを合わせて展開する］です。

タブ検索やタブグループのボタンが消えた

この 2 つのボタンは、右クリック →［固定を解除］で外せます。外したボタンを戻すときは、［設定］→［デザイン］で［タブ検索のボタンを表示する］か［ブックマーク バーにタブグループを表示する］をオンにします。

タブ検索は、キーボードでも開けます。Windows・Linux は Ctrl + Shift + A、Mac は ⌘ + Shift + A です。タブを探す方法は「Chrome のタブ検索とタブ一覧の出し方」にもまとめています。

縦か横か、迷ったときの目安

  • ページの題名を読んで探したい → 縦。公式ヘルプも、縦タブでできることの最初に「すべてのページの題名を確認する」を挙げています
  • ページの横幅を広く使いたい → 横。または、縦のままタブバーの幅を狭くする・たたむ
  • 決めきれない → 右クリックのメニューからすぐに行き来できるので、作業に合わせて切り替える

縦タブは「見せ方」。しまう・切り替えるのは、別の役目

縦でも横でも、開いているタブの数は変わりません。縦タブは、開いているタブの並べ方を変える機能だからです。元の悩みが「タブが多くて困る」なら、並べ方とは別に、閉じても、あとで仕事ごとにまとめて戻せる場所があると楽になります。

私たちが自分たちの仕事のために作った Chrome 拡張「LB TAB Layers」は、その役目の道具です。サイドパネルで、開いているタブを案件ごとのグループに保存します。保存先は Chrome のブックマークなので、タブを閉じても、ブックマークに残ります。■ でまとめて閉じ、▶ で、同じ名前・同じ色の Chrome のタブグループとして開き直せます。

縦タブとは役目が違うので、両方を一緒に使えます。縦タブにしていれば、▶ で開いたタブグループが、そのまま縦に並びます。横に戻した場合も、使い方は同じです。くわしくは「Chrome の縦タブの使い方」の後半と、「まとめて開くと、タブグループになる」をどうぞ。

まとめ

  • 横に戻す：縦に並んだタブかタブバーの空白を右クリック →［タブを横方向に表示］。または［設定］→［デザイン］→［タブの位置］で［横］
  • 出てこないとき：Chrome を最新にする（︙ →［ヘルプ］→［Google Chrome について］）→ ほかの入口を使う → パソコンの Chrome か、管理されている Chrome かを確かめる
  • 設定の場所：［設定］→［デザイン］。［タブの位置］、タブ検索とタブグループのボタン、［サイドパネルの位置］の左右
  • 左右：公式ヘルプに、縦タブの左右を選ぶ手順は載っていない（2026 年 11 月時点）。サイドパネルは左右を選べる
  • 縦タブは「見せ方」。タブを減らしたいときは、仕事ごとに保存して閉じられる場所を組み合わせる

よくある質問

Q. Chrome の縦タブを元に戻す（横に戻す）には？

縦に並んだタブか、タブバーの空白を右クリックして［タブを横方向に表示］を選びます。設定からなら、［設定］→［デザイン］→［タブの位置］で［横］を選びます。Mac は、画面の上のメニューの［表示］→［タブを縦方向に表示］のチェックを外しても戻せます。

Q. 「タブを縦方向に表示」がメニューに出てきません。

まず、右上の ︙ →［ヘルプ］→［Google Chrome について］で Chrome を最新にします。公式の提供は、Windows・Mac・Linux が Chrome 147 から、ChromeOS が Chrome 148 からです。右クリックで出ないときは、［設定］→［デザイン］→［タブの位置］か、︙ →［その他のツール］から選びます。職場や学校の Chrome は、管理者が機能を設定・制限していることがあります。

Q. Chrome の縦タブの設定は、どこにありますか？

［設定］→［デザイン］の［タブの位置］です。［縦］か［横］を選びます。タブ検索とタブグループのボタンを出す設定、サイドパネルを左右どちらに開くかの設定も、同じ［デザイン］にあります（2026 年 11 月時点の Google Chrome ヘルプの表記）。

Q. Chrome の縦タブを右側に出せますか？

2026 年 11 月時点の Google Chrome ヘルプには、縦タブの左右を選ぶ手順は載っていません。［タブの位置］で選べると書かれているのは［縦］と［横］です。当社で確かめた Chrome 157 の［設定］→［デザイン］にも、左右を選ぶ項目はありませんでした。サイドパネルのほうは、同じ［デザイン］で左右を選べます。

Q. 縦タブにしたら、タブ検索のボタンが見当たりません。

タブ検索とタブグループのボタンは、右クリック →［固定を解除］で外せます。戻すときは、［設定］→［デザイン］で［タブ検索のボタンを表示する］をオンにします。キーボードの Ctrl + Shift + A（Mac は ⌘ + Shift + A）でも、タブ検索を開けます。
