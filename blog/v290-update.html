LB TAB Layers v2.9.0 の主な変更は、①「タブ」「ブックマーク」「統合」「メモ」をワンクリックで切り替える画面レイアウト、②カード型のメモ＆チェックリスト、③独立ウィンドウ（別窓）や1つのタブとして開ける表示方法の3つです。ほかに、よく使うサイトの提案、OneTab からの乗り換え、空のグループへの右クリック保存の改善、Chrome 内蔵AIでの AI検索の修正、ピンバーに置ける数の拡大（12個まで）を行いました。いま使っている方は、これまでと同じ「統合」の画面のまま始まり、新しいレイアウトは案内から試せます。

LB TAB Layers の v2.9.0 を、2026年10月17日から Chrome ウェブストアで配信しています。今回のテーマは「見たいものを、見たい形で」です。開いているタブと保存したブックマークを分けて見る、サイドパネルではなく別の窓やタブで開く、作業のメモを横に置いておく。画面の使い方を、仕事や画面の大きさに合わせて選べるようにしました。

① 画面レイアウト — 「タブ」「ブックマーク」「統合」「メモ」を切り替える

サイドパネルのグループ一覧のすぐ上に、4つのボタンが並ぶ切替バーが加わりました。上部のモード（タブ・整理・スクショ・AI・DB）が「タブ」のときに表示されます。

ボタン表示されるもの
タブ開いているタブのうち、どのグループにも保存していないもの（単独タブ）を画面いっぱいに表示。下のタブで「本日の履歴」（PRO版／トライアル中）や「メモ」にも切り替えられます。ボタンの数字は単独タブの数です
ブックマーク保存したグループの一覧を画面いっぱいに表示。ボタンの数字はグループの数です（サブグループを含み、アーカイブしたものは除く）
統合これまでどおり、上にグループ一覧、下に単独タブ／本日の履歴／メモを並べて表示
メモメモ＆チェックリストを画面いっぱいに表示。数字はメモの枚数です

「タブ」「ブックマーク」「メモ」の3つは、1つの画面を広く使う切り分けレイアウトです。「統合」は、これまでの上下に並べる統合レイアウトです。最後に選んだ画面は保存され、次に開いたときもその画面から始まります。

ボタンの並びは、ドラッグで変えられます

4つのボタンは、つかんで左右にドラッグすると並びを入れ替えられます。よく使う画面を左端に置いておく、といった使い方ができます。並びは保存され、同じ Chrome で開いているほかの画面にも反映されます。

「タブ」画面から保存する2つの方法

切り分けレイアウトの「タブ」画面には、グループ一覧が出ません。そこで、画面を切り替えずに保存する方法を用意しました。

  • 行の「フォルダに保存」 — 単独タブの行にマウスを乗せると、右側にフォルダのアイコンが出ます。押すと「フォルダに保存 ›」「タブを閉じる」のメニューが出るので、「フォルダに保存」を押し、並んだグループから保存先を選びます（行の右クリックでも同じメニューが出ます）
  • 「ブックマーク」ボタンへドラッグ — タブの行をつかんで、切替バーの「ブックマーク」に重ねると、少しして「ブックマーク」画面に切り替わります。そのまま保存したいグループの上で離すと保存されます。ボタンの上で離しただけでは、画面が切り替わるだけで保存はされません

保存したタブは Chrome のブックマークになります。タブ自体は開いたままで、単独タブの一覧からは外れます。また、「タブ」画面で「新しいグループ」を押すと、自動で「ブックマーク」画面に切り替わってからグループを作ります。

ほかの切り替え方

  • 「新しいグループ」やダッシュボードのボタンが並ぶアイコンの列の、いちばん左のボタン（切り分けと統合を切り替えます）
  • 「設定」→「表示とテーマ」→「表示要素」→「画面レイアウト」で、「切り分け（タブ / ブックマーク）」か「統合（上下分割）」を選ぶ

💡 上下の境目をドラッグするリサイズと、下の欄の折りたたみは、「統合」のときに使えます。切り分けレイアウトでは、それぞれの画面が全体の高さを使います。

いま使っている方は、画面がそのまま変わりません

始まる画面表示される案内
これまで使っていた方（アップデートした方）これまでと同じ「統合」新しい「切り分けレイアウト」が選べるようになりました　［試してみる］［×］
新しく使い始める方切り分けレイアウトの「タブ」画面画面レイアウトはいつでも変更できます　［統合表示を試す］［×］

案内は、どちらかのボタンを押すまで、パネルを開くたびに表示されます。［試してみる］を押すと切り分けレイアウトの「タブ」画面に、［統合表示を試す］を押すと統合レイアウトに切り替わります。［×］で閉じたあとも、切替バーからいつでも切り替えられます。以前に使っていて、Chrome のブックマークからグループが戻った方も、これまでと同じ「統合」で始まります。

② メモ＆チェックリスト — パネルの中に、メモ帳と ToDo を

サイドパネルの中で使える、カード型のメモとチェックリストを加えました。Google Keep のように、1枚ずつカードで並ぶ形です（Google のサービスと連携する機能ではありません）。

開く場所は2つあります。

  • 切替バーの「メモ」 — 画面いっぱいに使えます
  • 下の欄の「メモ」タブ（「単独タブ」「本日の履歴」の隣）— 統合レイアウトなら、上でグループを見ながら下でメモを書けます

はじめて開くと、「クイックメモ」という名前のチェックリストが1枚できています。

操作できること
＋ メモを入力…文章のメモを一番上に作る
☑ チェックリストチェックリストを一番上に作る
Enterチェックリストで、すぐ下に新しい項目を足す（日本語の変換を確定する Enter では増えません）
Backspace空の項目で押すと、その項目を消して前の項目へ戻る
チェックを入れる項目がカード下の「完了したアイテム (N)」に移り、打ち消し線で表示される（見出しを押すと開閉）
ピン（カード右上）「固定済み」としてメモの一番上にまとめる
チェックボックスを表示/非表示文章のメモとチェックリストを切り替える（文章に切り替えると、チェックの印は消えます）
背景色を変更標準の色を含む8つから、カードの色を選ぶ
コピータイトルを「### タイトル」、チェックリストを「- [ ] 項目」「- [x] 項目」の形でコピー
テキスト保存 (.txt)コピーと同じ内容を .txt ファイルでダウンロード
このメモを削除確認のあとで削除（元に戻す機能はありません）

入力した内容は自動で保存され、文字を打ったあとに「✓ 自動保存済み」が少しのあいだ表示されます。同じ Chrome で開いているサイドパネル・別窓・タブ表示のあいだでは、内容が反映されます。

⚠️ メモの保存先について：メモはこのPCの Chrome の中（拡張機能の保存領域）に保存されます。グループやタブとは違って Chrome のブックマークには入らないため、ほかのPCには同期されず、拡張機能を削除すると消えます。「エクスポート (JSON)」にも含まれません。大事なメモは、コピーや .txt 保存で控えておいてください。

なお、保存したタブ1つずつに「なぜ残したか」を書いておくタブのメモは、これまでどおり使えます。今回のメモ＆チェックリストとは別の機能です。

③ サイドパネル以外で開く — 独立ウィンドウ（別窓）・新しいタブ

LB TAB Layers を、Chrome のサイドパネル以外の形でも開けるようになりました。ヘッダー右上、時計のアイコンの右隣にあるボタンを押すと、「表示方法を選択」のメニューが出ます。

メニュー開き方プラン
独立ウィンドウ（別窓）で開くタブバーやアドレスバーのない小さなウィンドウで開く。画面の好きな場所に置ける無料
新しいタブで開くブラウザの1つのタブとして、広く表示する無料
大画面ダッシュボードを開く2カラム＋カード一覧で全体を整理するPRO版／トライアル中
  • 別窓はサイズを覚えて、次回も同じ大きさで開きます。すでに開いていれば、ふだんは新しく増やさずに前に出します（タブ表示も同じです）
  • 別窓から操作しても、一覧には通常のブラウザウィンドウのタブが並び、タブもブラウザウィンドウ側で開きます
  • 単独タブの「表示中以外のタブを一括で閉じる」と、スクショモードの「このページを撮る」は、サイドパネルで使ってください。別窓やタブ表示では「表示中のページ」が LB TAB Layers 自身の画面と判断されるため、ブラウザで見ていたタブまで閉じる対象に入ったり、目的のページを撮れなかったりします

アイコンや Alt+T で、最初から別窓やタブで開く

④ よく使うサイトの提案

Chrome に残っている過去14日間の閲覧履歴から、よく使っているサイトを探して提案します。サイトごとに使った日数を数え、14日のうち3日以上使ったサイトが候補に並びます（最大20件）。8日以上使ったサイトには、最初からチェックが入っています。検索サイト（www.google.co.jp や bing.com など）、ログイン用のアドレス（accounts.google.com など）、IPアドレスや localhost などは数えません。

開き方は2つです。

  • グループ一覧の上に出る案内「よく使うサイトが○件見つかりました」の「見てみる」（切り分けレイアウトでは「ブックマーク」画面に出ます）
  • 「設定」→「データと同期」→「はじめる・乗り換える」→「よく使うサイトを見つける」（いつでも何度でも使えます）

一覧でチェックを付けて「追加する」を押すと、「📈 よく使う」グループに入ります。「ピンバーにも置く」にチェックが入っていれば（最初はオン）、ピンバーにも並びます。提案するだけで、自動で追加することはありません。

  • 「📈 よく使う」グループは、無料版のグループ数（5個）に数えません
  • グループに入れたサイトは、ほかのグループと同じく Chrome のブックマークとして保存されます
  • 案内は、14日のうち8日以上使ったサイトがあり、「📈 よく使う」グループがまだないときに出ます。×で閉じると、以後は出ません

🔒 集計はこのPCの中で行い、当社には送信しません（サイトのアイコンは、Chrome がこのパソコンに保存しているものを使うので、外には送られません）。使っているのは以前からの閲覧履歴とブックマークの権限で、このアップデートで新しい権限は増えていません。

⑤ OneTab から乗り換える

OneTab にためたタブを、LB TAB Layers のグループとして取り込めるようになりました。取り込みは無料です。

1

OneTab のテキストをコピーする

OneTab の「Export / Import URLs」を開き、表示されたテキストをすべてコピーします。

2

取り込みの画面を開く

LB TAB Layers の「設定」→「データと同期」→「はじめる・乗り換える」→「OneTab から乗り換える」を押します。

3

貼り付けて「取り込む」

貼り付けると「○グループ・○件を取り込みます」と表示されます。「取り込み先のグループ名」（最初は「OneTab から」）を確かめて、「取り込む」を押します。

  • OneTab で空行に区切られていたまとまりが、取り込み先グループの中のサブグループになります。名前は「グループ 1（12件）」のような形です（OneTab で付けたグループ名は、書き出したテキストに入っていないため引き継がれません）。まとまりが1つだけなら、取り込み先のグループに直接入ります
  • 取り込んだタブは Chrome のブックマークとして保存されます
  • すでに別のグループに保存してあるURLも取り込み、その件数を完了のお知らせで伝えます

ℹ️ 取り込みは、グループ数の上限で止まることはありません。ただし取り込んだグループ（サブグループを含む）も無料版の5グループに数えられるため、トライアル終了後は、一覧の先頭5グループ以外を使うには PRO版が必要です（データは Chrome のブックマークとして残ります）。

⑥ 空のグループへの右クリック保存を改善

Webページの右クリック「TAB Layers に保存」で、以前に作って空のまま残っていたグループを選ぶと、「サイドパネルを一度開いてから保存してください」と表示されて保存できないことがありました。v2.9.0 では、その場でグループのブックマークフォルダを作ってから保存します。サイドパネルを開いていなくても保存できます。

  • 今のページを「📥 あとで整理」に保存するショートカット（Ctrl+Shift+S、Macは Command+Shift+S）も、サイドパネルを一度も開いていない状態で使えるようになりました
  • グループに紐付いていたフォルダを Chrome 側で消してしまったグループや、名前が空のグループでは、「このグループはまだ準備中です。…」と表示されます。サイドパネルからタブを1つ保存すると、右クリックからも保存できるようになります

右クリック保存のこれまでの修正は「不具合のお知らせと修正（v2.8.72）」をご覧ください。

⑦ AI検索が Chrome 内蔵AIで動くように

AI検索（PRO版／トライアル中）で、AIエンジンに「Chrome Built-in AI (無料)」を選んでいると、今の Chrome ではエラーになって検索できない不具合がありました。v2.9.0 で、現在の Chrome の内蔵AIに対応しました。

  • 「設定」→「AI機能」で「AI機能を有効にする (Beta)」をオンにすると、検索欄に杖のアイコンのボタンが出ます
  • Chrome 内蔵AIは、PCの中で処理します。はじめて使うときは、Chrome がモデル（数GB）をダウンロードするため時間がかかります
  • 対応していないPCでは「この端末では Chrome 内蔵AI を利用できません…」と表示されます。そのときは、Gemini などのクラウドのAIを APIキーで使う方法を選べます（その場合、保存したタブのタイトルとURLが、選んだAIの事業者に送られます）
  • 「(無料)」は API の料金がかからないという意味で、AI検索そのものは PRO版／トライアル中の機能です

そのほかの変更

  • ピンバーは12個まで — ピンバーに置けるサイトを、10個から12個に増やしました

アップデート方法

Chrome ウェブストアから自動で更新されます。すぐに更新したい場合は chrome://extensions を開き、右上の「デベロッパー モード」をオンにして「更新」を押してください。保存したグループとタブは Chrome のブックマークに保存されているので、アップデートしてもそのまま残ります。

よくある質問

Q. アップデートすると、いつもの画面は変わりますか？

これまで使っていた方は、これまでと同じ「統合」の画面のまま始まります。サイドパネルに「新しい『切り分けレイアウト』が選べるようになりました」という案内が出るので、［試してみる］で切り分けレイアウトを試せます。案内は［試してみる］か［×］を押すまで、パネルを開くたびに表示されます。

Q. 新しいメモは、ほかのPCと同期されますか？

同期されません。メモはこのPCの Chrome の中（拡張機能の保存領域）に保存され、Chrome のブックマークには入りません。拡張機能を削除すると消え、「エクスポート (JSON)」にも含まれないので、大事なメモはコピーや .txt 保存で控えておいてください。

Q. 新しい機能は無料で使えますか？

画面レイアウトの切り替え、メモ＆チェックリスト、別窓・タブでの表示、よく使うサイトの提案、OneTab からの乗り換え、右クリック保存の改善は無料です。大画面ダッシュボード、オーバーレイ、AI検索、本日の履歴は、PRO版とトライアル中に使えます。

Q. よく使うサイトの提案で、閲覧履歴は送信されますか？

集計はこのPCの中で行い、当社には送信しません（サイトのアイコンは、Chrome がこのパソコンに保存しているものを使うので、外には送られません）。提案は自動では追加されず、チェックして「追加する」を押したものだけが入ります。

Q. 保存したグループやタブは、アップデートで消えませんか？

グループと保存したタブは Chrome のブックマークとして保存されているので、アップデートしてもそのまま残ります。
