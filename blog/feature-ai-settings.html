AIの設定とAPIキー
エンジン選びと安全な使い方

2026.09.24 · Liquid Block Inc. · 読了 4分

ポストシェアLINE送るB!ブックマーク

AI機能の設定は、設定画面の「AI機能」にまとまっています。エンジンはChrome内蔵AI（無料・キー不要）、Gemini（APIキー・無料枠あり）、OpenAI・Claude（APIキー・PRO版）から選べます。入力したAPIキーはこの端末内にのみ保存され、同期されません。

エンジンの違い

エンジンキー料金
Chrome内蔵AI不要無料（PCの中で実行）
GeminiGoogle AI Studio のキー無料枠あり
OpenAIOpenAI Platform のキー従量課金
ClaudeAnthropic Console のキー従量課金

検索欄のAI検索は4つのエンジンすべてに対応しています。AIサイドバーの会話は、現在Chrome内蔵AIとGeminiに対応しています。

Gemini APIキーの取得手順

1

Google AI Studio を開く

Google アカウントでログインします。

2

「Create API key」

キーを作成してコピーします。

3

設定画面に貼り付けて保存

LB TAB Layers の設定 →「AI機能」→ Gemini の欄に貼り付けて保存します。

キーはどこに保存される？

APIキーはこの端末内にのみ保存され、Googleアカウントの同期などで他の端末に送られることはありません。AIに質問したときに、そのキーの発行元（Google・OpenAI・Anthropic）にだけ送信されます。

ただし、ブラウザ拡張の仕組み上、キーを完全に隠すことはできません。「漏れても被害が小さい設定」にしておくのが安全です。

キーを守る設定

サービスやっておきたい設定
GeminiGoogle Cloud Console の「APIの制限」で、Generative Language API だけに限定
OpenAIOpenAI Platform でキーごとに利用上限（Usage limits）を設定
ClaudeAnthropic Console で使用上限（Spend limits）を設定

不安になったら、設定画面の「キーを削除」と、各サービスでの「キーの再発行」で無効にできます。

ℹ️ 設定画面の「AI機能を有効にする (Beta)」とAPIキーの入力は、PRO版と3ヶ月の無料トライアル中に利用できます。キーを用意しなくても、AIサイドバーではChrome内蔵AIで試せます。

よくある質問

Q. Gemini APIキーはどこで取得しますか？

Google AI Studioを開いてGoogleアカウントでログインし、「Create API key」でキーを作成します。LB TAB Layersの設定→「AI機能」→Geminiの欄に貼り付けて保存します。

Q. 入力したAPIキーは外部に送られますか？

APIキーはこの端末内にのみ保存され、同期されません。AIに質問したときに、キーの発行元のサービスにだけ送信されます。
