「気が利かない」と悩む人へ
察知力は「手札」で鍛えられる

2026.11.09 · 執筆：蔡本 英賛（株式会社リキッドブロック 代表） · 読了 7分

気が利く人は、相手の言葉の「背景」を、いくつか先に想像できています。「もし〜なら（IF）」「それとも〜か（OR）」という仮説の手札を持っていて、その中から選んだり、確かめたりしているのです。手札は、日頃見たものの背景を想像してメモに残すことでふやせます。外れてもよいので、仮説を持って聞くことが大切です。

「もう少し気を利かせて」と言われた。何をすればよかったのか、言われてみればわかる。でも、その場では思いつかなかった。そんなことが続くと、自分は向いていないのではと落ち込んでしまいます。

けれども、気が利くかどうかは、生まれつきの性格だけで決まるものではありません。この記事では、私たちが仕事の中で考えてきた「察知力（状況把握力）」の正体と、それを日頃から鍛える方法を紹介します。

結論：気が利く人は、相手の言葉の「背景」の手札を持っている

気が利く人は、相手が何か言ったとき、その言葉の背景をいくつか同時に想像しています。

  • IF（もし〜なら）：もしこういう事情があるなら、こうしてほしいのかもしれない
  • OR（それとも〜か）：それとも、別の事情があるのかもしれない
  • 選ぶ・確かめる：手札の中から、いちばんありそうなものを選ぶか、短く聞いて確かめる

つまり察知力とは、想像できる手札の数と、それを確かめる一言の組み合わせです。手札は経験でふえますが、日頃の練習でもふやせます。

「気が利かない」の正体は、手札の少なさと、聞く勇気

手札が少ないと、想像が1つしか出ない

相手の言葉に対して、思いつく背景が1つしかないと、それが外れたときに何もできません。あるいは、言葉どおりにしか受け取れず、「言われたことしかしない」と見られてしまいます。

外れたときの恥ずかしさが、先に立つ

もう1つの理由は、気持ちの問題です。「こういうことですか？」と聞いて外れたら恥ずかしい。そう思って黙っているうちに、聞くタイミングを逃してしまう。想像はできていたのに、聞きそびれたというのは、実はとても多いのです。

【実体験】「なぜこの人は今、天気の話をしたのか」

私たちは映像制作の会社で、お客さまとの打ち合わせや撮影の現場で、相手の言葉の裏を考える場面がたくさんあります。そこでよく考えるのが、「なぜこの人は今、天気の話をしたのか」ということです。

打ち合わせの最初に「今日は雨がひどいですね」と言われたとします。ただの雑談かもしれません。けれども、次のように手札を並べてみることができます。

手札想像した背景できること
IFもし移動が大変だったなら、少し疲れているかもしれない本題の前に飲み物をすすめる
ORそれとも、帰りの時間を気にしているのか「何時ごろまで大丈夫ですか」と最初に聞く
ORそれとも、屋外の撮影の天気が心配なのか雨の日の予備の案を先に出す

IF と OR が想像できていれば、その中の手札から選べます。どれか1つが当たっていれば、相手は「話が早い」と感じます。外れていても、「帰りの時間は大丈夫ですか」という一言は、失礼にはなりません。

逆に、外れたときの恥ずかしさが先に立つと、聞きそびれます。手札を持っていても、使わなければ持っていないのと同じです。

手札は、日頃の「背景を想像する練習」でたまる

手札をふやすいちばんの方法は、ふだん見たものの「背景」を想像するくせをつけることです。人と話すときだけでなく、ネットで見たニュース、会社の発表、SNSの投稿でも練習できます。

IF と OR の書き方

見たものIF（もし〜なら）OR（それとも〜か）
ある会社が値下げを発表したもし売れ行きが落ちているなら、在庫を減らしたいそれとも、新しい商品の前に入れ替えたいのか
取引先のサイトの採用ページが新しくなったもし人を増やすなら、新しい事業を始めるのかもそれとも、人が辞めて困っているのか

1日1つで十分

毎日たくさんやる必要はありません。1日1つ、「なぜ今これを？」と思ったものに、IF と OR を1つずつ書くだけです。続けると、相手の言葉を聞いたとき、自然に2つ以上の背景が浮かぶようになります。

題材は、仕事に近いものほど役に立ちます。取引先の業界のニュース、上司がよく見ているサイト、競合の新しいサービス。自分の仕事の相手が、いま何を気にしていそうかを想像する練習になるからです。通勤の電車でニュースを読んだら、1つだけ「なぜ今？」を考えてみる。それだけでも手札は少しずつたまります。

外れてよい。答え合わせができればもっとよい

仮説は外れてかまいません。あとで本当の理由がわかったら、メモに書き足します。当たった・外れたをくり返すうちに、手札の質が上がっていきます。

仕事でよく出る言葉と、手札の例

職場でも、言葉の裏に事情がありそうな場面はたくさんあります。次の表は、考え方の例です。正解を覚えるためではなく、「ほかにもありそう」と思えるようになるために見てください。

言われたことIFOR確かめる一言
「急ぎじゃないんだけど」もし本当に急ぎでないなら、今週中でよいそれとも、言いにくいだけで早めにほしいのか「いつごろあると助かりますか」
「最近どう？」（上司から）もし雑談なら、近況を一言それとも、進み具合が気になっているのか「○○の件は、いま半分です」と一言そえる
「資料、見ました」（だけで終わる）もし問題がないなら、それで終わりそれとも、言いたいことがあるが遠慮しているのか「気になったところはありましたか」

どの例でも、最後の列は短い質問です。手札が2つあるから、何を聞けばよいかがわかります。

仮説は「聞くため」に持つ

手札は、相手の気持ちを当てるためのものではなく、短く聞くためのものです。「〜ということですか、それとも〜ですか」と2つ出して聞けば、相手は選ぶだけで答えられます。外れても、もう1つの手札があるので、恥ずかしさは小さくなります。

聞くときの3つのコツ

  • 選べる形で聞く。「どうしますか」より「AとB、どちらがよいですか」のほうが、相手の負担が小さくなります。
  • 理由を短くそえる。「帰りの時間を先にうかがっておきたくて」と一言あれば、詮索ではなく気づかいだと伝わります。
  • 外れたら、すぐに引く。「失礼しました、では本題に」と流せば十分です。外れた手札は、次に生かせば無駄になりません。

ページにひもづけたメモに「IF／OR」を残す

この練習に、私たちが作った Chrome 拡張「LB TAB Layers」のメモを使っています。ネットで見たページに、そのページ専用のメモを付けられます。

  • サイドパネル（Alt+T）の「メモ」の画面で、リンクのボタン（このページのメモを作る）を押すと、今見ているページにひもづいたメモができます。
  • ページの中の気になる文を選び、右クリックの「選んだ文字をメモに追加」で、そのページのメモに足せます。その下に IF と OR を1行ずつ書きます。
  • あとで同じページを開くと、「このページのメモ」から、そのとき書いた仮説にすぐ戻れます。答え合わせを書き足すのに便利です。

メモは、このパソコンの中だけに保存されます（グループとタブは Chrome のブックマークに入りますが、メモは入りません）。取引先や人の名前を書くときは、そのことを覚えておいてください。

まとめ：察知力は、性格ではなく練習でふやせる

気が利く人は、相手の言葉の背景を IF と OR で想像できる手札を持っていて、外れることをおそれずに短く聞いています。手札は、日頃見たものの背景を想像して書きとめるだけでふえます。今日見たニュースを1つ選んで、「なぜ今これを？」に IF と OR を1つずつ書くところから始めてみてください。

🎬 ページのメモのほかにも、いろいろできます。パネルを開く、保存したタブを開く、閉じたタブを履歴から戻す、ページにひもづけたメモ、ピンバーまで。ブラウザとパネルの動きをそのまま見られる 操作ガイド（動く画面で見る10の操作） にまとめています。入れたばかりの方は クイックチュートリアル（5分） からどうぞ。

よくある質問

Q. 仕事で「気が利かない」と言われます。性格の問題でしょうか？

性格だけの問題ではありません。気が利く人は、相手の言葉の背景を「もし〜なら（IF）」「それとも〜か（OR）」でいくつか想像できる手札を持っています。手札は、日頃見たものの背景を想像する練習でふやせます。

Q. 状況把握力（察知力）は、どうすれば鍛えられますか？

1日1つ、ネットや仕事で見たものに「なぜ今これを？」と問いかけ、IF と OR の仮説を1つずつ書きます。あとで本当の理由がわかったら書き足して、答え合わせをします。

Q. 想像が外れるのが怖くて、聞けません。

「〜ということですか、それとも〜ですか」と2つ出して聞くと、外れてももう1つの手札があるので、恥ずかしさは小さくなります。仮説は当てるためではなく、短く聞くために持つものです。

Q. LB TAB Layers のページにひもづけたメモは、どこに保存されますか？

このパソコンの中だけに保存されます。グループとタブは Chrome のブックマークに入りますが、メモはブックマークには入りません。
