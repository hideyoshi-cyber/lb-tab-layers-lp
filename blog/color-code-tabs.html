タブを色分けして
ひと目で見分ける

2026.10.21 · Liquid Block Inc. · 読了 6分

ポストシェアLINE送るB!ブックマーク

Chrome では、タブグループを作ると9色から色を選べます。タブバーの上で仕事ごとに色が分かれ、ひと目で見分けられます。LB TAB Layers では、グループごとに8色のカラーと25種類のアイコンを選べ、閉じたあとの保存したタブも色で見分けられます。色は「意味」で決めて、数を増やしすぎないのが、迷わないコツです。

タブが10枚、20枚と並ぶと、タイトルの文字はほとんど読めなくなります。どれがA社の資料で、どれが社内の申請なのか、1枚ずつ確かめることになります。

そこで役に立つのが色分けです。文字を読まなくても、色で「どの仕事のものか」がわかります。この記事では、Chrome の標準の色分けと、LB TAB Layers での色分け、そして色をどう決めると迷わないかを説明します。

Chrome の標準：タブグループに色を付ける

Chrome には、タブをまとめて色を付ける「タブグループ」があります。

1

タブを右クリックして、新しいグループに入れる

まとめたいタブを右クリックし、「タブを新しいグループに追加」を選びます。

2

名前と色を決める

出てきた小さな画面で、グループの名前を入れて色を選びます。色は、グレー・青・赤・黄・緑・ピンク・紫・水色・オレンジの9色です。

3

ほかのタブも入れる

ほかのタブをグループの中へドラッグするか、右クリックから同じグループを選んで入れます。

グループの名前の部分を押すと、タブをたたんで細く見せることもできます。今開いているタブを、その場で見分けるには、とても手軽な方法です。

ただ、タブグループは「開いているタブ」の整理が中心です。仕事が終わって閉じたあとに、同じ色で残しておいて、あとで開き直したい、という使い方には、保存のしかたを別に考える必要があります。くわしい比べ方は「Chrome タブグループ vs タブ管理拡張」にまとめています。

LB TAB Layers：グループに色とアイコンを付ける

LB TAB Layers では、保存したグループに色とアイコンを付けます。グループは Chrome のブックマークのフォルダとして残るので、タブを閉じたあとも、色の付いたグループがサイドパネルに並んだままです。

1

グループを作るときに選ぶ

「＋」でグループを作ると、名前の下に「カラー」と「アイコン」が出ます。好きなものを押して「作成」を押します。

2

あとから変える

すでにあるグループは、右の「…」（その他のアクション）から「編集（名前・アイコン・色）」を選ぶと、いつでも変えられます。

選べるのは次のとおりです。

項目選べるもの
カラー（8色）赤・青・紫・緑・オレンジ・ピンク・水色・グレー
アイコン（25種類）フォルダ・かばん・コード・地球・カート・音符・写真・映画・本・学帽・ハート・星・ロケット・家・歯車・吹き出し・メール・カレンダー・クリップボード・棒グラフ・人・ゲーム機・パレット・植物・コーヒー

選んだ色は、グループの名前の左にあるアイコンに付きます。色で「どの仕事か」、アイコンで「何の種類か」を表せるので、2つを組み合わせると、たくさんのグループが並んでも見分けやすくなります。

💡 Chrome のタブグループの色と、LB のグループの色は、別のものです。LB で ▶ を押してタブを開いても、Chrome のタブグループは作られず、タブバーに色は付きません。また、Chrome のタブグループに入っているタブは、LB の「単独タブ」の一覧には出ません。そうしたタブを LB に保存したいときは、ページの上で右クリックして「TAB Layers に保存」を使ってください。

迷わない色の決め方：3つのルール

色分けは、最初はうまくいっても、グループが増えるとだんだん意味がなくなっていきます。次の3つを決めておくと、長く使えます。

ルール1：色には「意味」を1つだけ持たせる

いちばん大事なのは、色が何を表すかを1つに決めることです。「赤はA社、青は社内、緑は勉強」のように、色ごとに意味を決めます。「赤は急ぎ」と「赤はA社」が混ざると、赤を見ても何のことかわからなくなります。

ルール2：色は5つくらいまでにする

8色あっても、全部を使う必要はありません。人がすぐに思い出せる色の意味は、5つくらいまでです。足りないときは、色を増やすより、アイコンで分けるほうが迷いません。

ルール3：同じ種類のものは、同じアイコンにする

「会議の資料はカレンダー」「数字を見る画面は棒グラフ」「調べものは本」のように、種類ごとにアイコンをそろえます。色が顧客、アイコンが種類、と役割を分けると、組み合わせで見分けられます。

色の決め方の例

よくある分け方を2つ紹介します。そのまま使っても、自分の仕事に合わせて変えてもかまいません。

例1：取引先ごとに色を決める

色意味グループの例（アイコン）
青A社A社 提案（かばん）・A社 会議（カレンダー）
緑B社B社 制作（パレット）・B社 数字（棒グラフ）
オレンジC社C社 見積（クリップボード）
グレー社内毎朝（メール）・経費（クリップボード）

例2：仕事の種類ごとに色を決める

色意味グループの例
赤今週しめきりの仕事今週しめきりの案件
青ふだんの仕事進行中の案件
紫調べもの・勉強あとで読む・資料集め
グレー毎日の定型毎朝・月末の作業

例2のように「しめきり」で色を決める場合は、仕事が終わったら色を戻すのを忘れないようにします。グループの「…」から「編集（名前・アイコン・色）」で、すぐに変えられます。

色だけに頼らないために

色は便利ですが、似た色は見まちがえることもあります。色の見え方には人それぞれ差があるので、名前とアイコンも合わせて付けておくと確実です。

LB TAB Layers では、色やアイコンのほかにも、グループを見分ける方法があります。

  • 名前の頭をそろえる：「A社｜提案」「A社｜会議」のように始めると、一覧で並びが見やすくなります。
  • ★ランク：大事なグループに★を付けて、目立たせられます（→「★ランクとタグ」）。
  • 検索：どうしても見つからないときは、検索欄に名前の一部を入れれば、ひらがなでも探せます（→「タブをひらがな・カタカナで検索する方法」）。

なお、色とアイコンは LB TAB Layers の中の目印です。Chrome のブックマークのフォルダには色を付けられないため、ブックマークの管理画面では、ふつうのフォルダとして並びます。

色を決めておくと、タブを探して1枚ずつ確かめる時間が減ります。まずは今の仕事を3つくらい選んで、色を付けてみてください。

よくある質問

Q. Chrome のタブに色を付けられますか？

付けられます。タブを右クリックして「タブを新しいグループに追加」を選ぶと、グループの名前と色を決められます。色はグレー・青・赤・黄・緑・ピンク・紫・水色・オレンジの9色です。

Q. LB TAB Layers では何色から選べますか？

グループのカラーは、赤・青・紫・緑・オレンジ・ピンク・水色・グレーの8色です。あわせて25種類のアイコンから1つ選べます。

Q. 色はあとから変えられますか？

変えられます。グループの右の「…」から「編集（名前・アイコン・色）」を選ぶと、名前・アイコン・色をいつでも変えられます。

Q. LB で開いたタブに、Chrome のタブグループの色は付きますか？

付きません。LB TAB Layers の色はサイドパネルの中の目印で、Chrome のタブグループとは連動していません。

Q. Chrome のタブグループに入れたタブが、LB の単独タブに出てきません。

Chrome のタブグループに入っているタブは、単独タブの一覧には出ない作りです。LB に保存したいときは、ページの上で右クリックして「TAB Layers に保存」から保存先のグループを選んでください。
