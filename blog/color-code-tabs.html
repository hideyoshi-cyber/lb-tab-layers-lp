ひと目で見分ける

ポストシェアLINE送るB!ブックマーク

LB TAB Layers では、グループごとに8色のカラーと25種類のアイコンを選べます。色は「…」→「編集（名前・アイコン・色）」でいつでも変えられます。▶ でグループを開くと、タブは同じ名前・同じ色の Chrome のタブグループにまとまるので、サイドパネルとタブバーで同じ色の目印が使えます。色には意味を1つだけ持たせ、数を増やしすぎないのが、迷わないコツです。

タブが10枚、20枚と並ぶと、題名の文字はほとんど読めなくなります。どれがA社の資料で、どれが社内の申請なのか、1枚ずつ確かめることになります。

そこで役に立つのが色分けです。文字を読まなくても、色で「どの仕事のものか」がわかります。LB TAB Layers では、グループに付けた色が、そのままタブバーの色にもなります。

動く画面で見る：グループの色を変える

グループの「…」→「編集（名前・アイコン・色）」を押し、「カラー」で色を選んで「保存」。一覧のアイコンの色が変わります。

タブを仕事ごとにまとめて、▶ で開いて ■ で閉じる。

LB TAB Layers は、開いているタブを仕事ごとに Chrome のブックマークへ保存し、▶ ひとつで同じ名前・色のタブグループとして開き直せる、サイドパネルの拡張機能です。閉じても消えません。

グループに色とアイコンを付ける

1

作るときに選ぶ

「ブックマーク」の画面の一番上の「＋ 新しいグループ」を押すと、名前の下に「カラー」と「アイコン」が出ます。好きなものを押して「作成」を押します。

2

あとから変える

すでにあるグループは、右の「…」から「編集（名前・アイコン・色）」で、いつでも変えられます。

項目選べるもの
カラー（8色）赤・青・紫・緑・オレンジ・ピンク・水色・グレー
アイコン（25種類）フォルダ・かばん・コード・地球・カート・音符・写真・映画・本・学帽・ハート・星・ロケット・家・歯車・吹き出し・メール・カレンダー・クリップボード・棒グラフ・人・ゲーム機・パレット・植物・コーヒー

色で「どの仕事か」、アイコンで「何の種類か」を表せるので、2つを組み合わせると、たくさんのグループが並んでも見分けやすくなります。

▶ で開くと、タブバーも同じ色になる

グループの ▶ を押すと、中のタブがまとめて開き、グループと同じ名前・同じ色の Chrome のタブグループにまとまります。サイドパネルで「青はA社」と決めておけば、タブバーでもA社のタブは青です。■ を押すと、そのタブグループごと閉じます。

LB の8色は、Chrome のタブグループの色に、次のように対応します。

LB のグループの色Chrome のタブグループの色
赤・青・紫・緑・オレンジ・ピンク・グレー同じ系統の色
水色水色系の色（cyan）

Chrome のタブグループの黄色に当たる色は、LB の8色にはありません。▶ と ■ のくわしい動きは「Chromeのタブグループを自動で作る・まとめて閉じる」にまとめました。

迷わない色の決め方：3つのルール

ルール1：色には「意味」を1つだけ持たせる

「赤はA社、青は社内、緑は勉強」のように、色ごとに意味を決めます。「赤は急ぎ」と「赤はA社」が混ざると、赤を見ても何のことかわからなくなります。

ルール2：色は5つくらいまでにする

8色あっても、全部を使う必要はありません。すぐに思い出せる色の意味は、5つくらいまでです。足りないときは、色を増やすよりアイコンで分けるほうが迷いません。

ルール3：同じ種類のものは、同じアイコンにする

「会議の資料はカレンダー」「数字を見る画面は棒グラフ」「調べものは本」のように、種類ごとにアイコンをそろえます。

こんなふうに使うと便利

取引先ごとに色を決める

色意味グループの例（アイコン）
青A社A社 提案（かばん）・A社 会議（カレンダー）
緑B社B社 制作（パレット）・B社 数字（棒グラフ）
オレンジC社C社 見積（クリップボード）
グレー社内毎朝（メール）・経費（クリップボード）

A社とB社を ▶ で両方開いても、タブバーで青と緑に分かれるので、行き来するときに迷いません。

しめきりの近い仕事を赤に

「赤は今週しめきり」と決めておき、終わったら「…」→「編集（名前・アイコン・色）」でふだんの色に戻します。▶ で開いたとき、タブバーで赤いタブグループがすぐ目に入ります。

毎日の定型はグレー

「毎朝」「月末の作業」のような決まった仕事はグレーにしておくと、目立たせたい仕事の色が引き立ちます。

知っておきたいこと

  • タブグループにしたくないときは、設定で切れます。設定の「まとめて開くとき、Chrome のタブグループにする」をオフにすると、▶ はタブを開くだけになります
  • 色は「…」→「編集」で変えます。新しく作るときの最初の色は赤なので、意味を決めた色に選び直しましょう
  • Chrome のブックマークには色が付きません。グループは Chrome のブックマークのフォルダとして保存されますが、ブックマークの管理画面では、ふつうのフォルダとして並びます
  • 色だけに頼らない。色の見え方には人それぞれ差があります。名前とアイコンも合わせて付けておくと確実です。名前で探すなら ひらがなで探せる検索欄 も使えます

🎬 色分けのほかにも、いろいろできます。パネルを開く、保存したタブを開く、閉じたタブを履歴から戻す、ページにひもづけたメモ、ピンバーまで。ブラウザとパネルの動きをそのまま見られる 操作ガイド（動く画面で見る10の操作） にまとめています。入れたばかりの方は クイックチュートリアル（5分） からどうぞ。

よくある質問

Q. LB TAB Layers では何色から選べますか？

グループのカラーは、赤・青・紫・緑・オレンジ・ピンク・水色・グレーの8色です。あわせて25種類のアイコンから1つ選べます。

Q. 色はあとから変えられますか？

変えられます。グループの右の「…」から「編集（名前・アイコン・色）」を選ぶと、名前・アイコン・色をいつでも変えられます。

Q. LB で開いたタブに、Chrome のタブグループの色は付きますか？

付きます。▶ でグループを開くと、グループと同じ名前・同じ色の Chrome のタブグループにまとまります。水色は、Chrome の水色系の色（cyan）になります。設定の「まとめて開くとき、Chrome のタブグループにする」をオフにすると、タブグループにはしません。

Q. Chrome のブックマークのフォルダにも色が付きますか？

付きません。色とアイコンは LB TAB Layers の中の目印です。ブックマークの管理画面では、ふつうのフォルダとして並びます。
