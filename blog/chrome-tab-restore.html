PC再起動やクラッシュで消えたChromeのタブを復元するには、まずChromeを開いてすぐに Ctrl+Shift+T（Macは Cmd+Shift+T）を押してみてください。直前に閉じたタブが即座に復元されます。繰り返し押せば、閉じた順にさかのぼって、Chromeが覚えている範囲まで復元できます。それ以外にも、履歴（Ctrl+H）やChrome起動設定での復元方法があります。

Windows Updateで勝手に再起動された。突然のブルースクリーン。電源ボタンの長押し——。
そして起動したら、Chromeのタブが全部消えていた。

この記事では、消えたタブを復元する5つの方法と、次の再起動に備えて、タブをブックマークに残しておく方法を解説します。

消えたタブを復元する5つの方法

1

Ctrl + Shift + T で直前のタブを復元

最もかんたんな方法。Chromeを開いた直後に Ctrl + Shift + T（Mac: Cmd + Shift + T）を何度も押すと、閉じたタブが1つずつ復元されます。直前のセッションならほぼ復元可能です。

うっかり閉じた1枚を戻すだけなら、こちらの記事が早いです（→ 閉じたタブを元に戻すショートカット）。

2

Chrome の「最近閉じたタブ」から復元

タブバーの空いている場所を右クリック → 「閉じたタブを開く」。または右上の ︙ → 履歴 → 最近閉じたタブ から一覧表示できます。ウィンドウごと復元も可能です。

3

Chrome の履歴から探す

Ctrl + H で履歴ページを開きます。日付ごとにアクセスしたページが一覧表示されるので、目的のページを見つけてクリック。ただし、タブの「グループ」は復元できません。

4

「前回開いていたページを開く」設定を確認

chrome://settings/onStartup → 「前回開いていたページを開く」を選択。次回以降、Chrome起動時に前回のタブが自動復元されます。ただし、クラッシュ時は効かないことがあります。

5

Session Restore ファイルを復元（上級者向け）

Chromeはセッション情報を Default/Sessions/ フォルダに保存しています。バックアップがあれば、Session_* ファイルを置き換えることで復元できる場合があります。ただし成功率は低めです。

⚠️ 注意: 上記の方法はすべて「事後対応」です。Chromeの起動後に新しいタブを開いたり、時間が経つと復元できなくなります。消えたことに気づいたら、すぐに対応してください。

なぜ Chrome のタブは消えるのか？

Chromeのタブ情報は一時的なセッションデータとして保存されています。これは本質的に「揮発性」のデータです。

次の再起動に備える：ブックマークに残す

復元できた人も、できなかった人も、ひとつ覚えておいてください。Windowsの更新プログラムは毎月配信されます。再起動は、来月もまた来ます。

ここまでの5つの方法は、どれも「消えたあとに探す」方法です。次の再起動の前にできるのは、残したいタブを、消えない場所に置いておくことだけです。

その場所として使えるのが、Chromeのブックマークです。開いているタブは一時的なセッションデータですが、ブックマークはそれとは別に保存されています。ブックマークは：

  • PCを再起動しても残る（クラッシュのときも消えにくい）
  • Chrome拡張を削除しても残る
  • Googleアカウントで複数PC間で同期できる

手動で残すなら：Ctrl + D で1つずつ（Chrome標準）

拡張機能を入れなくても、Chromeだけで残せます。残したいタブを開いて Ctrl + D（Mac: Cmd + D）を押すと、そのページがブックマークに保存されます。

1つずつ残す方法なので、数枚ならこれで十分です。ただ、案件ごとに何枚も開いていると、どのタブをどのフォルダに入れたかを管理したり、あとでブックマークの中から探して開き直したりするのは手間がかかります。

案件ごとにまとめて残すなら：LB TAB Layers

LB TAB Layers は、サイドパネルに案件ごとの「グループ」を作り、残したいタブをそこへ保存していくタブ管理拡張です。グループに保存したタブは、Chromeのブックマーク（「LB TAB Layers」フォルダの中）になるので、PCを再起動しても残ります。

保存するタブは、自分で選びます。グループの ＋ ボタン（今見ているタブを追加）を押すか、サイドパネルに並んでいる開いているタブをグループへドラッグ＆ドロップすると、そのタブがブックマークとして保存されます（開いているタブをすべて自動で保存する機能ではありません）。再起動のあとは、グループの ▶ で保存したタブをまとめて開き直せます。

LB TAB Layers に保存したタブは：
タブを閉じても → ブックマークに残る
PC再起動しても → ブックマークに残る
拡張を削除しても → ブックマークに残る
サイドパネルのグループから、まとめて開き直せます。

まとめ

PC再起動やクラッシュでタブが消えた場合：

  1. Ctrl + Shift + T で直前のタブを復元
  2. 履歴から個別に探す
  3. 「前回のページを開く」設定をオンにする

そして次の再起動に備えるなら、残したいタブをあらかじめブックマークに保存しておくのがおすすめです。ブックマークは再起動しても残るので、消えたあとに探す手間を減らせます。
