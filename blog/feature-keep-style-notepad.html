メモ＆チェックリスト
ページの横で書いて、自動で保存

2026.10.23 · Liquid Block Inc. · 読了 7分

ポストシェアLINE送るB!ブックマーク

LB TAB Layers v2.9.0 から、サイドパネルにカード型の「メモ」が加わりました。上部の切替バーで「メモ」を押し、「メモを入力…」でテキストのメモ、「チェックリスト」でチェックボックス付きのリストを作ります。入力は自動で保存され、カードごとに8種類の背景色とピン留めで見分けられます。Markdown 形式のコピーと .txt 保存もでき、無料版で使えます。

v2.9.0 で、LB TAB Layers のサイドパネルにカード型のメモが加わりました。思いついたことを書きとめるテキストのメモと、チェックボックスで消していくチェックリストの2種類を、ページを見ながらその場で書けます。

以前からある「メモ機能」は、保存したタブ1つずつに「なぜ残したか」を書いておくひとことメモです。今回のメモは、タブとは別に、カードを何枚でも並べて使うメモ帳です。この記事では、こちらの使い方をまとめます。

💡 見た目は Google Keep のような「カードを並べる」形ですが、Google Keep と連携するものではなく、Google の機能でもありません。メモは LB TAB Layers の中に保存されます。

Chrome の標準機能でメモを書くには

Chrome のサイドパネルには、リーディング リスト・ブックマーク・履歴・リーディング モード・Google レンズなどを表示できます。ただ、Chrome ヘルプで案内されている標準の項目には、メモを書く機能はありません。

そのため、ページを見ながらメモを取るときは、メモアプリを別のタブやウィンドウで開いて行き来するか、サイドパネルに対応した拡張機能を使うことになります。LB TAB Layers のメモは後者で、タブの整理と同じパネルの中で書けるのが特長です。

メモを開く場所は2つ

LB TAB Layers を開き（ツールバーのアイコン、または Alt+T。Mac は Option+T）、上部のモードが「タブ」になっていることを確かめます。その下に「タブ」「ブックマーク」「統合」「メモ」の4つのボタンが並んだ切替バーがあります。

開き方見え方向いている場面
切替バーの「メモ」パネルの高さいっぱいにメモだけを表示メモをたくさん書く・読み返す
切替バーの「統合」→ 下の欄の「メモ」上にグループ一覧、下にメモ保存したページを見ながら書く

「メモ」ボタンの数字は、いまあるメモの枚数です。4つのボタンは左右にドラッグして並べ替えられるので、よく使う「メモ」を左端に置いておくこともできます。

ヘッダー右上（時計アイコンの右隣）のボタンから「表示方法を選択」のメニューを開き、「独立ウィンドウ（別窓）で開く」「新しいタブで開く」を選んだときも、同じメモが表示されます。

はじめて開いたとき

最初は「クイックメモ」という名前のチェックリストが1枚できています。そのまま1行目に書き始めてかまいません。メモはいつも1枚以上ある状態になっていて、最後の1枚を削除すると、カードは残って中身が空になります。

メモを作る

1

「＋ メモを入力…」でテキストのメモ

自由に書けるテキストのカードが一覧の先頭（ピン留めしたメモがあるときは、その下）にでき、そのまま入力できます。改行も使えます。

2

「☑ チェックリスト」でリスト

チェックボックス付きのカードが同じように先頭にでき、1行目に入力できる状態になります。

3

タイトルを付ける

カードの一番上の「メモのタイトル」に名前を入れておくと、あとで見分けやすくなります。タイトルは、コピーしたときの見出しや、.txt で保存したときのファイル名にもなります。

チェックリストの操作

操作動き
項目を入力して Enterすぐ下に新しい行ができ、続けて入力できる
空の行で Backspaceその行を消して、前の行の末尾に戻る
「＋ リスト項目を追加…」リストの最後に行を足す
行の右の ×（項目を削除）その項目を消す（行にマウスを乗せると表示）
チェックを入れるカードの下の「完了したアイテム (N)」に移り、打ち消し線とグレーで表示
チェックを外す元のリストに戻る

「完了したアイテム」の見出しを押すと、終わった項目を隠したり、もう一度表示したりできます。開いているか閉じているかは、メモごとに覚えています。

日本語入力で変換を確定するときの Enter では、行は増えません。確定したあとにもう一度 Enter を押すと、次の行に進みます。

カードのボタン

カードの右上にピン、下に5つのボタンがあります。どれもマウスを乗せると名前が出ます。

ボタンできること
ピン「メモを上部に固定」（右上）一覧の上の「固定済み」にまとめる。もう一度押すと外れる
チェックボックスを表示/非表示テキストのメモとチェックリストを切り替える
背景色を変更8つの色からカードの色を選ぶ
コピーMarkdown 形式のテキストでクリップボードへ
テキスト保存 (.txt)テキストファイルとしてダウンロード
このメモを削除確認のあとでカードを消す

ピン留め — よく見るメモを上に

ピンを押したメモは、一覧の上の「固定済み」にまとまり、ほかのメモは「その他」の下に並びます。新しく作ったメモは上に入るので、「今日の ToDo」のように毎日見るメモはピンで留めておくと、下に埋もれません。なお、並び順を変えられるのはピンの有無だけで、カードをドラッグして順番を変えることはできません。

8色の背景 — カードを色で見分ける

パレットのボタンを押すと、8つの丸が出ます。標準（テーマの色）のほか、赤・オレンジ・黄・黄緑・青緑・青・紫の淡い7色です。色の名前は表示されないので、丸を見て選びます。カードの色は、使っているテーマの色になじむ淡さで表示されます。

  • 赤：急ぎ・今日中
  • 黄：調べもの
  • 青：会議のメモ
  • 標準：そのほか

のように決めておくと、パネルを開いたときに、どのメモかを色で見分けられます。

テキストとチェックリストを切り替える

「チェックボックスを表示/非表示」を押すと、同じカードのままテキストとリストを行き来できます。

  • テキスト → リスト：1行が1項目になります。空の行は省かれます。行の頭が「- [x]」「☑」「✓」の行はチェック済みになり、「・」「*」「- [ ]」「☐」などの記号は取り除かれます。ほかのアプリで書いた箇条書きを貼り付けてから押すと、1行ずつのチェックリストになります（「-」や「•」だけで始まる行は、記号が残ります）。
  • リスト → テキスト：項目の文字が改行でつながります。チェックの状態は残りません（完了した項目も、印のない行になります）。もう一度リストに戻すと、すべて未チェックで始まります。

Markdown 形式でコピー・.txt で保存

「コピー」を押すと、次のような形でクリップボードに入ります。チャットやメール、Markdown が使えるノートアプリにそのまま貼れます。

コピーされるテキストの例：

### 定例の宿題
- [x] 見積の最新版を共有
- [ ] 来週の日程を調整
- [ ] 議事録を送る
  • タイトルは「### タイトル」の見出しになります
  • チェックリストは「- [ ] 項目」「- [x] 完了した項目」になります（完了した項目も、元の並び順のまま入ります）
  • テキストのメモは、書いた文章がそのまま入ります

「テキスト保存 (.txt)」は、同じ内容を「タイトル.txt」という名前のファイルでダウンロードします（タイトルが空なら note.txt）。保存先は Chrome のダウンロードの設定に従います。

保存のしくみと、気をつけること

保存ボタンはありません。文字を入力すると少しあとに自動で保存され、上のバーの右端に「✓ 自動保存済み」が少しのあいだ表示されます。チェック・ピン・色の変更・追加・削除は、押したときにすぐ保存されます。

こんなときメモは
パネルを閉じる・Chrome を再起動する残ります
同じ Chrome の別のウィンドウのサイドパネル・別窓・タブ表示同じメモが表示され、書き換えも反映されます
別のパソコン・スマートフォン同期されません
設定の「エクスポート (JSON)」含まれません（書き出されるのはグループだけ）
拡張機能を削除するメモも消えます

メモは、このパソコンの Chrome の中（拡張機能の保存領域）に保存されます。グループに保存したタブは Chrome のブックマークになるので、拡張機能を削除しても残りますが（→ 拡張機能を削除したらデータはどうなる？）、メモはブックマークとは別に保存されています。大事なメモは、コピーや .txt 保存で手元に控えておいてください。

  • 削除したメモを元に戻す機能（ゴミ箱）はありません。削除の前に確認が出るので、消してよいか確かめてから進めてください
  • 同じメモを2つの画面で同時に書き換えると、あとから保存した方の内容になります
  • 上の検索欄（「タブを検索…」）は、このメモの中までは探しません
  • メモの内容を当社に送ることはありません

ひとことメモとの使い分け

ひとことメモ（以前から）カード型のメモ（v2.9.0）
書く場所保存したタブ1つずつ（右クリック →「メモを編集」）切替バーの「メモ」、統合の下の欄の「メモ」
向いていること「なぜこのページを残したか」ToDo、調べもののメモ、会議の宿題
検索欄で探せるか探せる探せない
書き出しグループの Markdown コピー・JSON エクスポートに入るカードごとのコピー・.txt 保存

こんな使い方がおすすめ

  • 今日の ToDo — 朝に「今日」のチェックリストを作ってピン留め。終わったらチェックして、完了したアイテムにしまう
  • 調べもののメモ — ページを見ながら、わかったことをテキストのメモに。タイトルに調べものの名前を入れておく
  • 会議の宿題 — 会議中に出た宿題をチェックリストに書き、終わったら「コピー」でチャットに貼る
  • 手順の確認 — 設定の手順書を見ながら、やったことを1つずつチェック

思いついたことを書きとめる場所がページのすぐ横にあると、「あとで書こう」と覚えておく必要がなくなります。覚えておくための頭を、目の前の仕事に使えます。

よくある質問

Q. メモ＆チェックリストは無料で使えますか？

はい。無料版でも、メモの作成・チェックリスト・背景色・ピン留め・コピー・.txt 保存まで使えます。切替バーや統合レイアウトも無料です（下の欄の「本日の履歴」は PRO版とトライアル中の機能です）。

Q. メモはほかのパソコンやスマートフォンと同期されますか？

同期されません。メモはこのパソコンの Chrome の中に保存されます。同じ Chrome で開いている別のウィンドウのサイドパネルや別窓には反映されます。ほかの端末で見たいときは、コピーしてメールやチャットに貼るか、.txt で保存してください。

Q. 拡張機能を削除するとメモはどうなりますか？

メモも削除されます。グループに保存したタブは Chrome のブックマークとして残りますが、メモはブックマークとは別に保存されているためです。「エクスポート (JSON)」にもメモは含まれないので、残したいメモはコピーか .txt 保存で控えておいてください。

Q. 削除したメモを元に戻せますか？

戻せません。ゴミ箱や元に戻す機能はありません。削除の前に「メモ「タイトル」を削除しますか？」と確認が出ます。最後の1枚は、削除するとカードが残って中身が空になります。
