Chrome標準との違い

Chrome標準の機能より、ここが便利。

保存先は標準と同じChromeのブックマーク。標準の便利さはそのままに、足りないところだけを足します。

Chrome 標準
LB TAB Layers
タブグループ
Chrome 標準名前と色でまとめられ、閉じてもブックマークバーから開き直せる。ただし、グループの中にグループは作れない
LB TAB Layersグループの中にサブグループ。終わった案件はアーカイブ。構成はプリセットで一発作成。タブごとにメモと★
ブックマーク
Chrome 標準フォルダを「すべて開く」はできても、まとめて閉じる・今開いているかを見ることはできない
LB TAB Layers▶ でまとめて開き、■ でまとめて閉じる。開いているタブと保存したタブを同じ一覧で見分けられる
ブックマークの整理
Chrome 標準重複やリンク切れを見つける機能はない
LB TAB Layers全ブックマークから重複を検出。リンク切れもチェックして一括で片付け
検索
Chrome 標準入力した文字がそのまま含まれるものだけ。タブとブックマークは別々に探す
LB TAB Layers保存したタブ・開いているタブ・今日見たページ（PRO）をまとめて検索。「めーる」でGmailも
タブの保存と片付け
Chrome 標準☆で1ページずつ保存。保存していないタブは開いたまま増えていく
LB TAB Layers右クリックからグループへ保存。保存していないタブは一括で閉じる・サイトごとに自動でグループ分け
スクリーンショット
Chrome 標準複数のページをまとめて撮る機能はない
LB TAB Layersグループのページをまとめて撮影し、ZIPやPowerPoint（表紙・目次つき）で保存

標準と同じ場所に保存するから、LB TAB Layers をやめても、データはChromeにそのまま残ります。
